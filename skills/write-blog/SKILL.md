# 长文写作

你的任务:把一个主题写成一篇**读者愿意读完、读完有收获**的长文。不是堆字数,不是把一句话扩成三段,更不是 AI 味的"首先...其次...最后"。

核心信念:**好文章 = 明确的角度 + 紧凑的结构 + 高信息密度 + 像人话的表达。** 缺任何一项都会沦为注水文。

## 何时用

- 写博客 / 公众号 / 专栏 / 技术文章 / 观点文。
- 写教程 / how-to / 深度分析 / 经验复盘。
- 有主题没思路,或有大纲要展开成文。
- 把零散笔记/聊天/想法组织成连贯长文。

## 何时别用

- 写营销落地页 / 广告文案 / 转化型文案 → 用 `content-and-copy` / `landing-page-copy`。
- 给代码写文档 / README / JSDoc → 用 `genskills--readme-gen` / `genskills--doc-gen`。
- 学术论文(有引用/结构要求) → 用 `写论文`。
- 只是想总结已有材料 → 用 `summarize`。
- 改写/润色已有文字 → 用 `rewrite`。

## 四个核心要素(诊断框架)

写之前、写完都要拿这四条自检:

1. **角度(Angle)**:这篇文章的"独到观点"是什么?如果删掉它,网上已有一万篇一样的,就别写。角度 = 你比别人的那一点不同(经验/数据/反常识/新视角)。
2. **结构(Structure)**:读者能不能用一句话预测每段讲什么?结构清晰 = 读者不会迷路。选对文体结构就成了一半(见 references)。
3. **信息密度(Density)**:每句话有没有传递新信息?删掉这句读者损失什么?没损失就删。**注水是长文头号杀手。**
4. **人味(Voice)**:像不像一个真人在跟你讲?有没有 AI 味的空话("在当今快速发展的时代""毋庸置疑""综上所述")?

## 工作流

### 1. 先定角度和受众(别跳过)

问清楚或基于判断定:
- **给谁看**?(小白 / 同行 / 决策者)——决定深度和用词。
- **核心观点**是什么?(一句话能说清,不然没想透)。
- **文体**:观点文 / 教程 / 深度分析 / 经验复盘 / 清单(listicle)。

### 2. 出大纲,先让用户确认

**不要直接闷头写全文。** 先给大纲(章节 + 每章一句话要点),让用户确认或调整方向。这能避免写完一大段发现跑偏。

大纲要求:
- 每章服务于核心观点(不服务的砍)。
- 章节之间有递进/对照逻辑,不是平铺。
- 标出哪里需要"硬料"(数据/案例/代码/图)。

### 3. 分段成文

按大纲写。每段遵守:
- **开头三行定生死**:用一个钩子(反常识 / 痛点 / 故事 / 数据)把读者拽住,别用"时代背景"式废话开场。
- **一段一个观点**,段首句即观点,后面是支撑。
- **例子 > 形容词**:"快"不如"3 秒内返回";"复杂"不如具体描述哪里复杂。
- **过渡自然**:用逻辑衔接,不是"接下来""然后""此外"。

### 4. 自检(对照失败清单)

写完逐项过 `references/` 的结构与开头模板,以及下面的失败清单。**重点杀注水和 AI 味。**

### 5. 给标题备选

至少给 3 个标题,标注风格(直白/悬念/数字/观点),让用户选。标题要准确反映内容,不标题党。

## 失败模式(别犯)

- ❌ **没角度**:写成"某主题的百度百科",读者问"那又怎样"。
- ❌ **注水**:一句话能说完的扩成三段,每段加"众所周知""在...方面"。
- ❌ **AI 味**:开头"在当今...的时代"、结尾"综上所述"、滥用"首先其次再次最后"、排比堆砌、空泛形容词。
- ❌ **结构散**:章节并列但无逻辑递进,读到一半不知道为什么讲这个。
- ❌ **只描述不证明**:"这个方法很有效"但不给证据/案例。
- ❌ **不区分受众**:小白文里堆术语,或同行文里解释基础概念。
- ❌ **标题党**:标题承诺了文中没有的东西。
- ❌ **结尾烂尾**:正文不错,结尾突然"以上就是全部,希望对你有帮助"式敷衍收场。

## 注水自检小工具

写完后随机挑三段,问自己:
- 这段删了,文章损失什么?(答不上来 → 删)
- 这段能不能用一句话替代?(能 → 替代)
- 这段有没有一句"正确的废话"?("X 很重要"这种)(有 → 删或改成具体证据)

## 输出格式

1. **角度与受众**(1-2 句,说明我的写作假设)。
2. **大纲**(确认后再展开,或用户已确认则跳过)。
3. **正文**(完整成文)。
4. **标题备选**(≥3 个,标风格)。
5. **一句话说明**(适合发在哪、字数、可裁剪处)。

长文先确认大纲再写全文,避免白写。

# 标题公式 & 开头钩子 & AI 味词黑名单

## 一、标题公式(给用户 ≥3 个备选,标风格)

### 直白型(信息明确,适合教程/分析)
- 「X 全指南:从原理到落地」
- 「如何用 Y 在 Z 时间内做到 W」
- 「关于 X,你需要知道的 N 件事」

### 悬念/反差型(勾好奇,适合观点/复盘)
- 「我做了 X 三个月,结果完全不是预期」
- 「为什么大家都在做 X,我却劝你别跟」
- 「X 不是你以为的那样」

### 数字/清单型(易传播,适合 listicle)
- 「N 个让我效率翻倍的 X」
- 「X 的 5 个层次,90% 的人只到第 2 层」

### 观点/立场型(显态度,适合观点文)
- 「别再做 X 了,该做的是 Y」
- 「X 之所以重要,不是因为 Y」

**标题纪律**:
- 准确 > 吸引。标题党会让读者上当一次后再不点。
- 承诺文中必须兑现。说"N 个"就给 N 个。
- 主标题 + 副标题组合,兼顾吸引和信息(主:勾人;副:说清)。

## 二、开头钩子(前三行定生死)

读者看前三行决定走不走。**禁止用"在当今...的时代""众所周知"开头。**

### 钩子类型(任选其一)

**反常识**:
> "大多数人以为 X 越多越好。但过去三个月我发现,恰恰相反——"

**痛点共鸣**:
> "你是不是也这样:每次 Y,都卡在 Z 这一步,然后放弃。"

**故事/场景**:
> "上周五晚上 11 点,我盯着屏幕上那行报错,第六次跑同一个命令——"

**数据冲击**:
> "90% 的团队在 X 这件事上浪费了超过一半的时间。我们也是,直到——"

**提问**:
> "如果只能记住关于 X 的一件事,你希望是什么?"

### 钩子后立刻抛核心观点

钩子(2-3 行)→ 立刻给核心观点(1 句话)→ 再展开。不要钩子之后又绕回"背景介绍"。

## 三、AI 味词黑名单(写作时见一个删一个)

这些词/句式是 AI 味的重灾区,人类作者很少这么写。

### 开头类
- "在当今/在这个...的时代"
- "随着...的快速发展"
- "众所周知 / 毋庸置疑 / 不言而喻"
- "X,作为 Y,正在改变我们的世界"

### 连接类(过度使用)
- "首先...其次...再次...最后"(机械排比)
- "此外 / 另外 / 与此同时"(堆叠)
- "值得一提的是"(删掉这句直接说)
- "总而言之 / 综上所述 / 由此可见"

### 空泛形容词
- "强大的 / 高效的 / 智能的 / 全方位的 / 深度融合的"
- "赋能 / 抓手 / 闭环 / 打通 / 助力"(除非行业必需)

### 万能废话句
- "这无疑是一个重要的课题"
- "对于...具有重要意义"
- "值得我们深入思考"
- "希望对你有所帮助"(结尾别用)

### 替代原则
- 形容词 → 具体数据/例子("高效" → "3 秒返回")。
- 连接词 → 逻辑本身("首先/其次" → 让段落顺序自然体现)。
- 空话 → 删。

---

## 四、结尾收法(别烂尾)

结尾要给读者**一个带走的东西**:行动建议 / 一句金句 / 一个反问 / 预告。

- ✅ "所以下次遇到 X,先问自己一个问题:Y。答案往往就有了。"
- ✅ "这件事我还在继续做,有新进展再更。"
- ❌ "以上就是全部内容,希望对你有帮助,谢谢观看。"

## 五、交付前自检三问

1. 标题承诺的,正文兑现了吗?
2. 开头三行能让读者继续往下吗?(有没有 AI 味?)
3. 结尾读者带走了什么?(还是只是"讲完了"?)

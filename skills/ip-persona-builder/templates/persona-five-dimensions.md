## 维度五:视觉符号(提升识别度)

**作用**:在信息流里一眼认出。缺失=淹没在同质化封面里。

| 元素 | 你的设定 |
|---|---|
| 主色(1-2个,贯穿封面/头像) | |
| 字体风格(手写/无衬线/粗黑) | |
| 标志性构图(如固定人物位置/固定色块) | |
| 固定道具/场景(如某个杯子/某面墙) | |
| 头像/封面统一感 | |

判断:把你的封面和十个同类账号混在一起,粉丝能否 3 秒认出?

### 分平台视觉符号建议表(必读 `platform` 配置后选行填写)

> 视觉符号不是平台中立的——同一套主色字体,落到不同平台的内容形态上差别极大。先读 SKILL.md 配置里的 `platform`,按下表给**与该平台对应**的视觉方案,再把上表的"主色/字体/构图/道具/头像"填到能直接在该平台执行的程度。`platform="通用"` 时按最后一行处理。

| platform | 主导内容形态 | 封面/视觉重点 | 识别机制 | 视觉符号设计要点 |
|---|---|---|---|---|
| 小红书 | 图文笔记(9 宫格) | **第一张封面 3:4 竖图决定点击率**,封面字大且少(≤8字)、高对比 | 封面统一样式 + 合集封面连贯 | 给固定封面模板(如"截图+红圈批注"型)、9 宫格视觉连贯逻辑、合集封面统一框架 |
| 抖音 | 竖屏短视频(≤60秒) | 封面=视频高光帧缩略图,**前 3 秒视觉钩子**决定完播 | 头像+昵称+签名 + 人物出镜记忆点 | 给固定片头 3 秒画面、口播人物固定机位/穿搭/背景墙、字幕样式 |
| 公众号 | 长文 | 头图 900×383 + 文内分隔线/配图风格 | 头图样式 + 排版风格 + 次条封面 | 给固定头图模板、内文配图风格(实景/手绘/数据图)、分隔线与配色体系 |
| B站 | 横屏中长视频(5-15分钟) | **16:9 封面**封面字+人物夸张表情,分区投稿封面规范 | 封面 + 弹幕互动 + 三连引导 | 给固定封面构图(字+人+色块)、片头三连引导动画、分区封面差异 |
| 知乎 | 文字为主(问答/专栏) | 头像 + 一句话签名 + 专栏头图 | 头像签名 + 文风 + 配图风格 | 给头像风格、签名句式、配图(信息图/思维导图)统一风格 |
| 通用 | 未指定平台 | 跨平台统一主色+字体+构图逻辑 | 主色+字体+构图跨平台一致 | 先定主色/字体/构图"母版",再说明各平台只做尺寸适配(小红书竖图/抖音竖屏/B站横屏等) |

**自查**:你给的视觉符号方案是否与 `platform` 行匹配?如果换一个 platform 方案会明显不同 = 正确(说明 platform 真的影响了建议);如果换 platform 方案不变 = 没消费 platform,重写。

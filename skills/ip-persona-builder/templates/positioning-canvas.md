# 定位三角画布 + 一句话定位模板

> 本模板配套 Step 1(定位三角分析)与 Step 2(一句话定位)。复制填写,用于诊断与产出定位。

---

## 一、定位三角画布

把你的能力、目标人群、差异化填进三圈,找交集。**交集 = 你的定位**。

### 圈一:我能持续输出什么(能力 / 经验 / 资源)

| 维度 | 你的填写 | 判断 |
|---|---|---|
| 核心技能(能教/能讲/能做) | | 未来一年每周产出不枯竭? |
| 独特经验(别人没有的) | | |
| 可调用资源(人脉/渠道/案例) | | |
| 兴趣驱动(愿意长期投入) | | |

### 圈二:谁需要(目标人群的真实痛点)

| 维度 | 你的填写 |
|---|---|
| 人群描述(具体到年龄/职业/阶段) | |
| 他们最痛的 1-3 个问题 | |
| 他们现在怎么解决(现状) | |
| 他们愿意为什么付费 | |

### 圈三:凭什么是你(差异化壁垒)

| 维度 | 你的填写 |
|---|---|
| 经历稀缺性 | |
| 跨界组合点 | |
| 独特观点/框架 | |
| 个人故事(抄不走) | |

### 诊断结论

- 三圈交集(一句话定位雏形):________________
- **最弱的圈是:______,原因:______,补强动作:______**
- 定位锐利度自评(1-5):______(低于 3 分需重审)

## 二、一句话定位(三版本模板)

### 版本 A:电梯演讲版(30-50字,口头自我介绍)

公式:**我帮[谁]用[什么方法]解决[什么问题]**

填写:我帮 ____________________________________,用 ____________________________________,解决 ____________________________________。

完整句:____________________________________________________________

示例:我帮 30 岁想转行的职场人,用结构化定位法,解决"不知道自己能做什么"的迷茫。

### 版本 B:主页简介版(15-25字,账号简介/名片)

公式:**我是[领域]里最懂[细分人群]的[身份]**

填写:我是 ____________ 领域里,最懂 ____________ 的 ____________。

完整句:____________________________________________________________

示例:职场领域里最懂"30+转行焦虑"的定位教练。

### 版本 C:口号版(8-12字,封面/签名/传播)

公式:**动词 + 对象 + 独特承诺**

填写:____________ + ____________ + ____________

完整句:____________________________________________________________

示例:帮转行人,48小时找到方向。

### 三版互相校验

- A 写不出 → 定位太泛,回到圈二把人群具体化。
- B 写不出 → 差异化不足,回到圈三补壁垒。
- C 写不出 → 没记忆点,回到人设五维补口头禅。

### 分平台内容形态表(必读 `platform` 配置后给每个支柱配形态)

> 内容支柱只有"选题"是不够的——同一选题在不同平台的**载体形态、篇幅、钩子位置、互动玩法**完全不同。先读 SKILL.md 配置里的 `platform`,按下表把每个支柱的"示例选题"落成**该平台可直接发布**的形态。`platform="通用"` 时按最后一行处理(给选题、形态留待用户定平台后补)。

| platform | 载体形态 | 篇幅/时长 | 钩子位置 | 互动玩法 |
|---|---|---|---|---|
| 小红书 | 图文笔记(1-9 张图)+ 正文 | 图 9 宫格 + 正文 500-800 字 | 标题<20 字钩子 + 首图封面 | 话题标签 3-5 个、合集/置顶、评论区置顶答疑 |
| 抖音 | 口播短视频 | 60 秒内 | **前 3 秒**钩子决定完播 | 字幕必备、BGM+热点、评论区运营+置顶 |
| 公众号 | 长文 | 2000-4000 字 | 标题 + 头图 | 留言区互动、次条做轻量内容、在看/转发 |
| B站 | 中长视频(知识区口播+画面剪辑) | 5-15 分钟 | 封面+标题 + 开场 15 秒 | 弹幕互动、三连引导、分区投稿、专栏文章辅助 |
| 知乎 | 问答 / 专栏长文 / 想法 | 长文 3000 字深度 | 首段结论前置 | 回答高赞问题蹭流量、专栏、想法(短动态) |
| 通用 | 平台中立(给选题,形态待定) | 按支柱类型给量级建议 | 提示"选定首发平台后补钩子位置" | 提示"定平台后补互动玩法" |

**支柱总表"内容形态"列填写说明**:上表最后一列"内容形态(读 platform 后填)"是模板写死的强制列、不是可选扩展——按下述分平台表填到"该平台可直接发布"的程度,留空=没消费 platform,飞轮和冷启动都会脱节。写清该支柱在你平台上的载体+篇幅+钩子+互动。示例(platform=小红书,支柱①):"图文 9 宫格 / 每篇 600 字 / 标题钩子+首图红圈批注 / 话题#简历优化#求职 + 评论区置顶诊断入口"。

**自查**:如果换一个 platform,你给的内容形态会明显不同 = 正确(platform 真的影响了建议);如果换 platform 形态不变 = 没消费 platform,按上表重写。

## 三、支柱验收(逐条过)

对每个支柱回答:

| 验证问题 | ① | ② | ③ | ④ | ⑤ |
|---|---|---|---|---|---|
| 它在强化我的哪个定位标签?(一句话) | | | | | |
| **这条支柱砍掉后,定位会不会塌一角?** | | | | | |
| 我能不能周更这个支柱至少 3 个月不竭? | | | | | |

**判断标准**:

- 砍掉后定位塌一角 = 核心支柱,必须保留。
- 砍掉后无影响 = 在稀释定位,删除或合并。
- 周更 3 个月会竭 = 不在能力半径内,换掉。

任一支柱答不出"强化哪个标签",回到定位三角重审——支柱存在的唯一理由是给定位加码,不是凑数量。

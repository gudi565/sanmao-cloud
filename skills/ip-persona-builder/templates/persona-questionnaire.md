# IP 定位结构化提问清单

> 本清单配套 Step 0,用于收集足够信息再开始定位。**注意分模式**:A 多轮对话模式下严格禁止替用户编答案(没问到就问);B 单次产出模式下允许对缺口做最小必要推断并标 `[推断·待确认]`,详见 SKILL.md Step 0 模式判定。

---

## 使用说明

- 用户在 argument 里已提供的信息直接填入,不重复问。
- 信息密度不足(只有"我是产品经理"这种一句话)时,用本清单追问到"能举例"的程度。
- 不必逐条机械问——挑信息缺口问,保持对话感。

## 信息完整度判断

收集到以上七类后,做一次自检:

| 检查 | 通过? |
|---|---|
| 能说出 2-3 个具体技能且各有例子 | [ ] |
| 能描述目标人群的具体一天 | [ ] |
| 资源约束(时间/平台)清晰 | [ ] |
| 性格与表达风格有方向 | [ ] |
| 变现意向明确(哪怕是"开放") | [ ] |

**按 Step 0 模式判定走分叉(不要两种模式混着用):**

- **A 多轮对话模式**:全部通过 → 进入 Step 1 定位三角分析;仍有缺口 → 针对性追问,**不得硬开始、不得替用户编答案**。
- **B 单次产出模式**(用户只给了 argument、本轮必须产出成品):缺口不必停下——把缺字段标 `[推断·待确认]`(只有用户自己知道的事实如真实案例数字标 `[需用户提供]`),继续推进到 Step 7,在文末"待确认清单"逐项列出向用户确认。**推断只限"让定位成立"的结构性字段(人群/时间量级/风格偏向),不得推断事实性字段,也不得在结论里把推断当事实。**

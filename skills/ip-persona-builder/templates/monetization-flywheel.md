## 二、变现路径选择决策表

按你的定位与阶段选主路径(1条)+ 备选(1条)。不是选"最赚钱"的,是选"和定位最自洽"的。

| 变现路径 | 对定位的要求 | 启动门槛 | 适合阶段 | 收入天花板 | 你的匹配度(1-5) |
|---|---|---|---|---|---|
| 咨询/教练 | 垂直信任强、案例可证 | 低 | 1000粉可试 | 中(受时间限制) | |
| 知识付费/课程 | 专业度高、方法论成体系 | 中 | 1万粉后 | 高(可复用) | |
| 社群/会员 | 价值观认同强、互动活跃 | 中高 | 1万粉后 | 中高(续费) | |
| 带货/分销 | 受众消费意图明确 | 中 | 需稳定流量 | 中(看品类) | |
| 广告/商单 | 泛流量或垂直流量均可 | 高 | 需稳定更新+体量 | 中(看垂直度) | |
| 训练营/陪跑 | 专业度高+运营能力强 | 高 | 1万粉后 | 高(高客单) | |

### 选择原则

1. **先低门槛验证**——咨询/教练可在 1000 粉阶段跑通,验证"定位是否被付费需要"。
2. **再复制放大**——验证后把服务产品化(课程/训练营),突破时间天花板。
3. **路径不贪多**——主路径 1 条做透,再考虑第二条。同时铺 3 条=都做不好。
4. **与定位自洽**——定位是"方法论型"适合课程/咨询;定位是"生活方式型"适合带货/社群。

## 三、飞轮自洽性检查

| 检查项 | 是/否 |
|---|---|
| 内容支柱是否在持续强化变现所需的专业形象? | |
| 目标人群是否有明确的付费意愿与付费能力? | |
| 第一个产品是否解决的是人群最痛的问题? | |
| 变现后是否有机制把案例反哺成内容? | |

任一项为"否",定位与变现存在错位——回到定位三角或内容支柱调整,而不是硬推产品。

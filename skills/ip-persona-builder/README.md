# 个人IP人设定位

> 把"我想做个人IP"拆解成一份可直接指导内容创作与变现的定位文档。

## 这是什么

很多人做 IP 卡在起点,不是没东西可写,而是定位不清——内容发散、受众模糊、变不了现。这个 skill 把模糊的"我想做 IP"变成一份可执行的结构化文档:你是谁、给谁、解决什么、凭什么选你、怎么持续产出、怎么变现、第一步做什么。它封装了七个经过验证的方法论(定位三角、一句话定位公式、差异化提炼法、人设五维、内容支柱、变现飞轮、冷启动路径),通过分步提问与诊断产出成稿,复制即用。

## 30秒上手

1. **安装**:把整个 `ip-persona-builder/` 文件夹放到 `~/.claude/skills/` 下(或项目级 `.claude/skills/`)
2. **调用**:在 Claude Code 里输入 `/ip-persona-builder <你的职业/经验/目标>`
3. **拿结果**:按 skill 的分步流程产出完整定位文档,复制即用

调用示例:

```
/ip-persona-builder 5年产品经理 想做副业知识付费
```

## 它能帮你做什么

- **诊断定位**:用"定位三角"判断你的能力、人群、差异化哪圈最弱,给出补强动作
- **产出一句话定位**:按电梯演讲 / 主页简介 / 口号三个场景各出一版,互相校验
- **提炼差异化标签**:从五个维度挖出 3-5 个"不同而非更好"的标签,避免"全能型"陷阱
- **定义人设五维**:专业背景、性格、价值观、口头禅、视觉符号逐维落地
- **设计内容支柱**:用"支柱选题映射法"反推 3-5 个固定内容方向,不让内容稀释定位
- **规划变现路径**:画变现飞轮、选主路径+备选,并给当前阶段的冷启动动作清单

## 适合谁

- **想做个人 IP 的职场人**:有经验但不知道怎么包装成定位
- **咨询师 / 教练 / 知识工作者**:需要把专业能力转化成可记忆的人设
- **自由职业者**:内容发散、受众模糊、变现路径不清
- **想转型的专业人士**:想用副业做 IP,但每周只有有限时间投入

## 包含什么

- `SKILL.md` — 主文件(285 行):七大核心方法论 + 八步工作流(Step 0–7)+ 自检清单 + 端到端示例
- `templates/persona-questionnaire.md` — 结构化提问清单(22 题 / 7 章节),收集足够信息再开工
- `templates/positioning-canvas.md` — 定位三角画布 + 一句话定位三版本填写模板
- `templates/persona-five-dimensions.md` — 人设五维逐维填写表
- `templates/content-pillars.md` — 内容支柱推导表 + 逐支柱验收清单
- `templates/monetization-flywheel.md` — 变现飞轮图 + 六种变现路径决策表
- `LISTING.md` 是市场上架文案,买家可忽略

## 常见问题

- **要不要联网?** 不需要。skill 只用 Read / Write,基于你的输入做定位推演,不联网检索。
- **能不能自定义?** 可以。放一个 `_config.json` 到 skill 目录下即可设置平台、阶段、变现偏好等(见下节)。在调用时随口提到的信息(如"我在小红书""想做咨询")也会被自动识别。
- **支持什么平台 / 语言?** 默认中文输出;通过 `platform` 字段可适配小红书 / 抖音 / 公众号 / B站 / 知乎等,影响内容支柱与视觉符号建议。

## 配置(可选)

读取同目录 `_config.json`,不提供就用内置默认。关键字段:

| 字段 | 默认 | 说明 |
|---|---|---|
| `platform` | `"通用"` | 目标平台,影响支柱与视觉符号建议 |
| `stage` | `"0→1000"` | 当前阶段,影响冷启动建议侧重点 |
| `monetization_pref` | `[]` | 变现意向偏好(如 `["咨询","课程"]`),为空则全路径推荐 |
| `tone` | `"专业真诚"` | 输出语气倾向 |
| `language` | `"zh"` | 输出语言 |

无 `_config.json` 也能开箱即用,所有字段走默认。

# 改写工具箱:动作清单 + AI 味黑名单 + 用词对照 + 范例

## 一、各维度改写动作清单

### 精简(去冗)
- 删"的/了/进行+动词":"进行分析" → "分析";"进行讨论" → "讨论"。
- 删正确的废话:"众所周知""毋庸置疑""不可否认"——全删。
- 合并重复:同一意思说了两遍的,留一遍。
- 长句拆短:超过 30 字的句子拆成两句。
- 删空壳:"我认为 X 是非常重要的" → "X 很重要"(删"是...的""我认为"如果非必要)。

### 口语化
- 书面词 → 日常词:"获悉"→"知道";"拟"→"打算";"兹"→"现在";"予以"→"给"。
- 短句 + 语气词(合适处加"其实""说白了""讲真")。
- 拆长句、加口语连接("然后""就是说")。
- 去四字成语堆砌(口语里没人那么说话)。

### 正式化
- 完整句,省略主语要谨慎。
- 规范用词(但不要堆古词/官腔)。
- 结构更严谨:总分总、论点先行。
- 去口语语气词("啊""呢""嘛")。

### 专业感
- 用领域准确术语(确认受众懂)。
- 逻辑链清晰:因为-所以、前提-结论。
- 数据支撑观点,不靠形容词。
- 删修辞,留信息。

### 去 AI 味(最常做)
见下"AI 味黑名单"。核心动作:
- 删机械排比("首先...其次...最后")。
- 删空泛形容词("强大的""高效的""深度的")。
- 删套话开头结尾("在当今...的时代""综上所述")。
- 让过渡自然,不用"此外""与此同时"硬接。

### 换受众
| 受众 | 改写重点 |
|---|---|
| 老板/决策者 | 结论先行、数据、省过程、说影响 |
| 客户 | 利益点、价值、少术语、解决他什么问题 |
| 小白 | 多比喻、少术语、补背景、拆步骤 |
| 同行 | 直接上术语、给细节、省科普 |
| 大众 | 有钩子、短、口语、避免黑话 |

## 二、AI 味词黑名单(改写时见一个删一个)

### 开头套话
- "在当今/在这个...的时代"
- "随着...的快速发展/普及"
- "众所周知 / 毋庸置疑 / 不言而喻 / 不可否认"
- "X,作为 Y,正在深刻改变..."

### 机械连接
- "首先...其次...再次...最后"(改用自然过渡)
- "此外 / 另外 / 与此同时 / 值得一提的是"
- "总而言之 / 综上所述 / 由此可见 / 不难看出"

### 空泛形容词(替换成具体)
- "强大的 / 高效的 / 智能的 / 全方位的 / 深度的 / 海量的"
- "赋能 / 抓手 / 闭环 / 打通 / 助力 / 赋能"(行业黑话除非必要)

### 万能废话
- "这无疑是一个重要的课题/问题"
- "对于...具有重要意义/价值"
- "值得我们深入思考/探讨"
- "希望对你有所帮助/谢谢观看"(结尾)

### 修复原则
- 形容词 → 具体数据/例子。
- 套话 → 删。
- 排比 → 让逻辑本身体现顺序。

## 三、口语 ↔ 正式 ↔ 专业 用词对照

| 口语 | 正式 | 专业(示例领域) |
|---|---|---|
| 知道 | 获悉 / 了解 | (领域词) |
| 想要 | 期望 / 拟 | — |
| 觉得 | 认为 | 判断 |
| 说 | 表述 / 称 | 陈述 |
| 弄好 | 完成 / 办妥 | 交付 |
| 很多 | 较多 / 众多 | 大量 / 高基数 |
| 大概 | 大致 | 约 / 估算 |
| 因为 | 由于 | 鉴于 / 基于上述 |
| 所以 | 因此 | 故 / 据此 |
| 但是 | 然而 / 但 | 反之 / 相对地 |

**注意**:不要无脑往右改——过度正式 = 官腔,也是一种毛病。匹配受众。

## 四、改写范例

### 范例 1:精简 + 去 AI 味(工作汇报)

原文:
> 在当今快速发展的业务环境下,我们的团队毫无疑问地进行了一次深入的复盘。首先,我们对上季度的数据进行了分析;其次,我们发现了转化率存在显著的下降趋势;最后,我们制定了相应的优化方案,希望能够有效地提升相关指标。

改写:
> 上季度转化率下降了。我们复盘了原因,定了优化方案,目标下季度回升。

(信息全保,字数减 70%,AI 味清零。)

### 范例 2:换受众(同一件事)

事件:上线了一个新功能,首周 DAU 涨 15%。

给老板:
> 新功能上线首周 DAU +15%,验证了假设。建议加大投入,预计月内能撑起整体增长目标。

给同事:
> 新功能这周上了,DAU 涨了 15%。主要拉动来自 X 路径,埋点数据在 [链接],可以看看。

给大众(社交):
> 我们做了个小功能,结果比预期好——这周用的人多了 15%。分享下我们怎么想的👇

### 范例 3:口语化(客服话术)

原文(书面):
> 关于您反馈之问题,我们已获悉并正在进行核实,届时将予以回复。

改写(口语友好):
> 你说的这个问题我们看到了,正在查,查清楚马上回你。

## 五、改写自检清单

- [ ] 要点没丢(对照原文骨架)?
- [ ] 语气/受众/长度对准目标了?
- [ ] AI 味清了吗?(读出声像人话)
- [ ] 数字/术语/专有名词没动?
- [ ] 没夹带原文没有的信息/观点?
- [ ] 个人风格没被抹平(轻度润色时)?

## 六、一句话

改写的本质:**同一个意思,换个更适合当前场景的说法。** 内容不动,表达换骨。

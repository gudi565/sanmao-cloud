# 自媒体选题日历

> 输入赛道 + 平台 + 周期，产出一张可直接排期的一周/一月选题矩阵。

## 这是什么

这是一套给自媒体人用的系统性选题工具，解决"今天发什么"这个最反复、最消耗心力的痛点。它封装了六块被验证的方法论——内容三层矩阵（引流/信任/转化）、内容支柱法、选题角度裂变、热点借势评分、发布时间策略、平台差异化改编——按分步工作流跑完后，交付一张可直接复制到飞书/Notion/表格的选题矩阵表，外加一份让账号长期不再跑偏的内容支柱清单。不是帮你列个选题表，而是给一套能反复用的选题体系。

## 30 秒上手

1. **安装**：把整个 `content-calendar/` 文件夹放到 `~/.claude/skills/` 下（用户级），或项目级 `.claude/skills/`。
2. **调用**：在 Claude Code 里输入 `/content-calendar <赛道> <平台> <周期>`，缺的信息 skill 会追问。
3. **拿结果**：按 Step 0→6 跑完，复制矩阵表即用。

调用示例：

```
/content-calendar 美妆 小红书 一周
/content-calendar 职场 公众号 一个月
```

## 它能帮你做什么

- **按账号阶段定配比**：起号/增长/变现三期对应不同的引流:信任:转化比例，自动算出本周各层该发几篇。
- **从定位推导内容支柱**：用"账号定位 ∩ 读者需求"公式锚定 3-5 个固定话题方向，让读者有预期、算法好推流。
- **一个话题裂变 7-21 个选题**：7 种角度（5W2H/反常识/对比/清单/故事/盘点/场景）把母话题扩成选题池，告别"写完就没得写"。
- **热点该不该蹭有评分**：相关性 × 速度 × 调性匹配三维打分，≥6 才蹭，避免硬蹭伤号。
- **匹配各平台发布时段**：引流放流量高峰、深度放阅读时段，含小红书/公众号/抖音/视频号/B站/知乎的时段表。
- **一鱼多吃不搬运**：同一选题按平台形态重写钩子，跨平台错峰发布不被判抄袭。

## 适合谁

- **全职自媒体人**：天天被选题逼到断更，想要一套能持续产出的体系而非灵感。
- **品牌新媒体/运营团队**：多账号、多平台排期混乱，需要标准化选题流程。
- **MCN 与矩阵操盘手**：旗下账号同质化被限流，需要分账号差异化支柱。
- **刚定位完的新号**：第一次排期不知道从哪下手，需要从支柱到排期一条龙。

## 包含什么

- `SKILL.md` — 主文件（225 行）：六块核心方法论 + Step 0→6 分步工作流 + 9 条质量自检清单 + 边界避坑。
- `templates/topic-matrix.md` — 选题矩阵表（核心交付物）：含一周示例、空白周模板、月历按周分块骨架，复制即用。
- `templates/pillar-template.md` — 内容支柱定义画布：从"我是谁 × 读者要什么"推导 3-5 个支柱，含完整示例。
- `templates/angle-ideation.md` — 选题角度裂变法：7 角度速查表 + 每角度子模板 + 去重对照。
- `templates/hotspot-calendar.md` — 热点借势：三维评分表 + 12 个月节日/行业事件日历框架 + 借势卡模板。
- `LISTING.md` — 市场上架文案，可忽略。

## 看看效果

以下是 `templates/topic-matrix.md` 里真实的示例矩阵（美妆 / 小红书 / 增长期 / 一周）：

```
| 日期 | 选题 | 角度 | 支柱 | 层级 | 平台 | 时段 | 预期目标 |
|------|------|------|------|------|------|------|---------|
| 周一 | 换季爆痘别慌,3 步急救法 | 场景 | 护肤科普 | 引流 | 小红书 | 12:00 | 涨粉 200+ |
| 周二 | 我坚持早 C 晚 A 半年的脸 | 故事 | 护肤科普 | 信任 | 小红书 | 21:00 | 收藏 500+ |
| 周三 | 贵妇霜 vs 平价替代,谁值 | 对比 | 产品测评 | 引流 | 小红书 | 12:30 | 互动 300+ |
| 周四 | 刷酸烂脸的 3 个常见误区 | 反常识 | 成分避坑 | 引流 | 小红书 | 20:00 | 涨粉 250+ |
| 周五 | 敏感肌自救指南(干货合集) | 盘点 | 护肤科普 | 信任 | 小红书 | 21:30 | 收藏 800+ |
| 周六 | 5 支平价修护单品清单 | 清单 | 好物清单 | 引流 | 小红书 | 12:00 | 涨粉 150+ |
| 周日 | 为什么这款精华我自费回购 3 次 | 5W2H | 产品测评 | 转化 | 小红书 | 20:30 | 咨询 20+ |
```

## 常见问题

- **要不要联网？** skill 含 WebSearch 权限，但仅用于核实可预判热点（节日/大促/行业大会）的当年准确日期，或补国际/英文热点。**中文实时热搜（微博/抖音/小红书）WebSearch 覆盖很弱**，Step 5 的热点采集优先用你粘贴的中文来源或第三方数据平台（千瓜/新榜/飞瓜/巨量算数）。
- **能不能自定义？** 可以。在项目根目录或 `content-calendar/` 下放一个 `_config.json` 预填赛道、平台、阶段、配比、已有支柱等默认值；不放也行，全程用默认值并在产出里标注"（默认）"。
- **支持什么平台/语言？** 面向中文自媒体，内置小红书、公众号、抖音、视频号、B站、知乎六个平台的时段与改编策略。

## 配置（可选）

不放 `_config.json` 即开箱即用。常用了的字段：

| 字段 | 作用 | 缺省 |
|------|------|------|
| `stage` | 账号阶段：`起号` / `增长` / `变现` | `增长` |
| `ratio` | 自定义三层配比，覆盖阶段默认 | 按阶段查表 |
| `pillars` | 已有内容支柱，老号直接复用 | Step 1 推导 |
| `peak_hours` | 你自校准过的各平台真实高峰 | 用默认时段表 |
| `taboo_topics` | 不碰的话题（合规/调性） | 空 |

读取优先级：调用参数 > `_config.json` > 默认值。凡用到默认值的地方，产出里都会标注"（默认）"提示你校正。

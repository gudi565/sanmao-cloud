# 选题永动机 · 自媒体选题日历
> 一周 7 篇选题一次排完，复制进表格就能用

## 🎯 一句话介绍

想选题是自媒体最反复的内耗——断更就掉粉、瞎发就伤号。这是给中文自媒体人的一套**可执行选题体系**：输入赛道+平台+周期，输出一张带日期、标题、角度、内容支柱、层级、发布时段、预期目标的**排期矩阵表**，直接复制进飞书/Notion/表格就能用。它不是帮你"随便列个选题表"，而是把内容三层矩阵（引流/信任/转化）、内容支柱法、7 角度裂变法、热点借势评分、发布时段策略、平台差异化改编这六套方法论封装进去——你拿到的不只是 7 个标题，而是一套能反复跑、不再每天从零想的选题系统。

- **品牌新媒体 / 运营团队**：老板要排期、要数据、要转化，缺的是一套"配比合理+目标可量化"的选题框架，而不是又一堆零散灵感
- **MCN / 多账号矩阵操盘手**：多账号同时排期、各号支柱要差异化防限流，靠人脑根本排不过来
- **刚起号的新手**：不知道引流/信任/转化怎么配，照搬默认 5:3:2 结果硬广超标掉粉——这个 skill 直接按你的阶段（起号/增长/变现）给对的配比
- **代运营 / 内容服务商**：需要稳定、可复用、客户能看懂的交付物，矩阵表就是天然的交付件

## ✨ 核心卖点

1. **交付的是"排期表"不是"灵感清单"** —— 每条选题带日期、标题、角度、支柱、层级、平台、时段、预期目标共 8 个字段，选题本身无需二次加工，复制进表格即可排期。市面上多数 AI 选题工具只给一堆标题词，这个给的是带时段与目标的成品。
2. **按账号阶段自动给对的配比** —— 起号期 7:2:1 / 增长期 5:3:2 / 变现期 3:4:3，自动算出引流/信任/转化各几篇，还带凑整规则（转化层宁少勿多，避免硬广超标掉粉）。这是新手最容易错的点，照搬默认配比直接伤号。
3. **中文平台 + 本土场景，不是翻译货** —— 时段表覆盖小红书/公众号/抖音/视频号/B站/知乎六个中文平台的真实活跃时段；热点借势明确指出 WebSearch 是 US-only、对微博热搜覆盖弱，教你正确用千瓜/新榜/飞瓜等中文数据源。英文 skill 落地到中文赛道最常踩的坑，这里都帮你填了。
4. **一套方法论，反复跑一辈子用** —— 内容支柱定一次（3-5 个）全程不变；7 角度裂变让一个母话题扩成 7-21 条选题，足够一个月用。买的不是一次性的 7 个标题，是"再也不每天从零想选题"的系统。
5. **自带质量自检 + 避坑清单** —— 9 条交付前自检（配比偏差、支柱覆盖、角度重复、时段匹配…）+ 10 条边界避坑（新号时段靠猜、借势翻车高发区、多账号同质化限流、AI 撞题的人设化改写…）。等于附送一个资深运营帮你审稿。
6. **跨平台一鱼多吃，不是复制粘贴** —— 同一选题按平台形态重写钩子与正文（小红书图文短钩子 / 公众号长文干货 / 抖音前 3 秒钩子），还附跨平台错峰发布原则，吃满各平台高峰且避免自我流量竞争。

## 📝 真实产出示例

这是 skill 跑一遍"美妆 / 小红书 / 一周 / 增长期"完整产出的选题矩阵（摘自 `templates/topic-matrix.md` 示例，定位=成分党护肤博主，4 根支柱=护肤科普/产品测评/成分避坑/好物清单，配比 4:2:1）：

| 日期 | 选题 | 角度 | 支柱 | 层级 | 时段 | 预期目标 |
|------|------|------|------|------|------|---------|
| 周一 | 换季爆痘别慌，3 步急救法 | 场景 | 护肤科普 | 引流 | 12:00 | 涨粉 200+ |
| 周二 | 我坚持早 C 晚 A 半年的脸 | 故事 | 护肤科普 | 信任 | 21:00 | 收藏 500+ |
| 周三 | 贵妇霜 vs 平价替代，谁值 | 对比 | 产品测评 | 引流 | 12:30 | 互动 300+ |
| 周四 | 刷酸烂脸的 3 个常见误区 | 反常识 | 成分避坑 | 引流 | 20:00 | 涨粉 250+ |
| 周五 | 敏感肌自救指南（干货合集） | 盘点 | 护肤科普 | 信任 | 21:30 | 收藏 800+ |
| 周六 | 5 支平价修护单品清单 | 清单 | 好物清单 | 引流 | 12:00 | 涨粉 150+ |
| 周日 | 为什么这款精华我自费回购 3 次 | 5W2H | 产品测评 | 转化 | 20:30 | 咨询 20+ |

跑完还会自动做配比自检：引流 4 / 信任 2 / 转化 1，角度 7 篇 7 个不重复，引流放午休晚高峰、信任放阅读时段——这才是"买完能产出的东西"，不是空话。

**选题是怎么裂出来的，也给你看一眼**（摘自 SKILL.md 示例）：以"换季护肤"为母话题套 7 角度——场景→"换季爆痘急救"、反常识→"别在换季猛刷酸"、清单→"5 个平价修护单品"……一个母话题就能扩出一周候选池，再按配比挑 7 条；而内容支柱定一次全程不变，下个月换个母话题接着跑。所以买的不是一次性 7 个标题，是一台能反复开的选题机器。

## 🚀 怎么用

1. 把 `content-calendar/` 整个文件夹放到 `~/.claude/skills/` 目录下
2. 在 Claude Code 里输入 `/content-calendar 美妆 小红书 一周`（或你的赛道+平台+周期），缺的信息它会追问你
3. 拿到一张可直接排期的选题矩阵表 + 一份内容支柱清单，复制进飞书/Notion/表格开干

> 支持 `_config.json` 预置默认支柱、配比、时段偏好，多账号可各存一份配置。

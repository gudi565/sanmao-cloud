# 热点借势:判断标准 + 日历框架

> 用途:决定一个热点该不该蹭、怎么蹭,并提前储备可预判热点。对应 SKILL.md 方法论 4、工作流程 Step 5。

## 借势判断公式

```
借势价值 = 相关性(0-3) × 速度(0-3) × 调性匹配(0-2)
最高 18 分(3×3×2),门槛:≥6 蹭,<4 放弃,4-5 看把握。
```

## 三维评分表

| 维度 | 分值 | 评分锚点 |
|------|------|---------|
| 相关性 | 0-3 | 3=正好命中你的支柱;2=沾边能拐回来;1=勉强相关;0=纯无关 |
| 速度 | 0-3 | 3=6h 内发;2=24h 内;1=48h 内;0=超过 2 天 |
| 调性匹配 | 0-2 | 2=口吻天然契合;1=需要微调语气;0=强行变味 |

| 总分 | 决策 |
|------|------|
| ≥ 6 | 值得蹭,优先产出 |
| 4-5 | 有把握快速产出且不翻车才蹭 |
| < 4 | 放弃,硬蹭伤号 |

## 热点分两类

- **可预判型**:节日、节气、大促、行业大会、影视定档——提前 7-14 天储备内容,当天/前夜发布。
- **突发型**:社会事件、热搜爆点——靠速度,黄金 6 小时内出手;超 24h 基本是尾声。

## 借势三原则

1. **相关性优先于速度**:再热但跟账号无关的热点,相关性 0 分,直接放弃。借势的本质是给支柱内容借个钩子,不是追热搜。
2. **借势不复制热搜文案**:把热点当开头钩子(1-2 句带过),主体仍是你的支柱内容。读者要的是"你的观点",不是复读机。
3. **三类绝不蹭**:社会悲剧/灾难、政治敏感、未核实的企业负面。调性风险永远 > 流量收益。

## 每周滚动复盘(月历专用)

突发热点无法预排,每周末做一次:**优先从用户提供的中文热点来源捞**(微博热搜 / 抖音热榜 / 小红书热点 / 千瓜 / 新榜 / 飞瓜 / 巨量算数——WebSearch 是 US-only,对中文实时热搜覆盖弱,仅用来核实节日日期或补国际热点)→ 跑一遍三维评分 → 通过的(≥6)替换下周的引流位。可预判型(节日/大促)保持原排期不动。

> 实操提示:每周末可固定问用户一句"本周你赛道有哪些热搜/爆点?",把热点采集的责任明确交给最接近一线的人,避免 AI 凭 US-only 检索硬凑出不相关的"伪热点"。

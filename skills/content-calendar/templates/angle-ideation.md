# 选题角度裂变法(Angle Ideation)

> 用途:同一母话题裂变出 7-21 个子选题,解决"一个话题写完就没得写"。对应 SKILL.md 方法论 3、工作流程 Step 3。

## 裂变公式

```
1 个母话题 × 7 种角度 = 7 条选题(每角度再扩 1-3 条 → 最多 21 条)
```

## 7 种角度速查表

| # | 角度 | 核心句式 | 适合的层级 | 示例(母话题:时间管理) |
|---|------|---------|-----------|---------------------|
| 1 | 5W2H | 为什么/是什么/怎么做/何时/谁 | 信任(科普) | 为什么你的时间总是不够用 |
| 2 | 反常识 | 反过来讲、颠覆常识 | 引流(爆款) | 时间管理反而让我更累? |
| 3 | 对比 | A vs B / 以前 vs 现在 | 引流(抉择) | 番茄钟 vs 时间块,谁更高效 |
| 4 | 清单 | N 个方法 / N 个工具 | 信任(工具) | 7 个让效率翻倍的时间法 |
| 5 | 故事 | 亲身经历 / 学员案例 | 信任(人设) | 我用这套方法 30 天读完 5 本书 |
| 6 | 盘点 | 年度/系列/合集 | 引流(合集) | 2026 时间管理 10 大趋势 |
| 7 | 场景 | XX 时怎么办 | 信任(场景) | 拖延到最后一刻怎么办 |

## 裂变工作流

1. **选母话题**:从某个内容支柱下挑一个读者关心的核心问题(如"早起""阅读""存钱")。
2. **套 7 角度**:用上表句式,每角度写 1-3 个候选标题(先不筛,越多越好)。
3. **标层级**:每个候选标注它属于引流/信任/转化(参考上表"适合的层级"列)。
4. **去重筛选**:标题读者一眼分不出差异的合并;和账号调性不符的删掉。
5. **入池备用**:通过的选题进选题库,排期时按配比挑用。

## 扩展:每角度的子模板

- **5W2H 七连**:Why(为什么) / What(是什么) / How(怎么做) / When(何时做) / Where(在哪做) / Who(谁该做) / How much(花多少)。一个话题直接出 7 条。
- **反常识三种**:结果反转("越努力越穷?") / 常识证伪("早起其实不健康?") / 反向操作("别做时间管理了")。
- **对比三种**:方案对比(A 法 vs B 法) / 时间对比(过去 vs 现在) / 人群对比(新手 vs 高手)。
- **清单变体**:N 个工具 / N 个习惯 / N 个误区 / N 个资源 / N 个阶段。
- **故事三种**:亲身(我做对了什么) / 翻车(我踩的坑) / 学员(他怎么做到的)。
- **盘点维度**:年度 / 季度 / 行业 / 工具榜 / 误解榜。
- **场景切入**:按时间(早晨/深夜)、按人群(学生/宝妈)、按状态(焦虑/拖延)、按场合(通勤/加班)。

## 去重对照(发现重复就合并)

如果两条选题在读者眼里"看起来差不多",通常是同一角度的子变体。合并标准:核心论点相同 → 合并成一条;只是举例不同 → 留更具体的、删笼统的。

# 自媒体选题日历

"今天发什么"是自媒体最反复、最消耗心力的痛点——想不出选题就断更,瞎发就掉粉。这个 skill 不是帮你"列个选题表",而是一套被验证的选题体系:先用内容支柱锚定账号定位,再用三层矩阵分配引流/信任/转化,用角度裂变把一个话题扩成一组选题,再匹配发布时段与热点借势。最终产出一张可直接排期的选题矩阵,以及一套让你不再每天从零想的支柱清单。

适用于:周/月选题规划、新号定位后第一次排期、多账号矩阵的内容调度、热点周期(节日/大促/行业事件)前的储备。

## 核心方法论

本 skill 的产出全部由以下六块方法论驱动,缺一不可。每一块都对应一个可复用的结构化工具(见 templates/)。

### 1. 内容三层矩阵(引流 / 信任 / 转化)

每篇内容都该回答一个问题:**它为账号贡献什么**——拉新、养信任、还是促转化。把所有选题归入三层,避免"全是引流不转化"或"全是硬广掉粉"。

| 层级 | 核心目标 | 典型内容 | 衡量指标 | 默认配比 |
|------|---------|---------|---------|---------|
| 引流层 | 拉新 / 播放 / 阅读 | 蹭热点、大众话题、情绪共鸣、争议观点 | 曝光、涨粉、互动率 | 50% |
| 信任层 | 养信任 / 留存 | 干货、经验、方法论、人设故事、观点 | 完播/完读、收藏、关注转化 | 30% |
| 转化层 | 促转化 / 变现 | 产品种草、案例、客户见证、促销、发售 | 点击、咨询、成交 | 20% |

**不同阶段配比不同**(这是新手最常错的点——照搬默认 5:3:2):

| 阶段 | 引流 | 信任 | 转化 | 判断逻辑 |
|------|------|------|------|---------|
| 起号期 | 70% | 20% | 10% | 粉丝基数小,优先曝光拉新,硬广比例压到最低 |
| 增长期 | 50% | 30% | 20% | 已有基础流量,开始沉淀信任,试探转化 |
| 变现期 | 30% | 40% | 30% | 流量自循环,重心转向信任和成交 |

名额换算公式:**周期发文名额 × 层级配比 = 该层选题数**。例如一周 7 篇、增长期:引流 4 / 信任 2 / 转化 1。

**凑整规则**(配比乘出来是小数时怎么取舍):小数优先补到**引流层**(起号 / 增长期)或**信任层**(变现期),**转化层宁少勿多**,避免硬广超标掉粉。例如一周 7 篇、增长期 5:3:2 = 3.5 / 2.1 / 1.4 → 引流 3.5 向上凑 4、信任 2.1 向下取 2、转化 1.4 向下取 1,即 4 / 2 / 1;而非 3 / 2 / 2(后者转化层超标,增长期硬广过多易掉粉)。

### 2. 内容支柱法(Pillar)

账号必须有 3-5 个固定话题方向(支柱),所有选题挂在支柱下。价值三重:读者有预期(关注的理由)、算法好归类(精准推流)、作者不偏题(定位清晰)。

**推导公式:内容支柱 = 账号定位 ∩ 读者需求**

拆解两边:

- **账号定位(我是谁)**:专业身份 / 独特经历 / 资源优势 / 人设标签
- **读者需求(读者要什么)**:求知(学方法) / 求证(避坑) / 求安(情绪共鸣) / 求用(工具资源)

支柱数量 **3-5 个最佳**:<3 定位过散、算法难推流;>5 读者记不住、账号没记忆点。同一支柱下要保持视角一致(例如"护肤科普"支柱就别突然发八卦)。

> 支柱定义画布详见 `templates/pillar-template.md`,含从定位推导支柱的完整步骤与示例。

### 3. 选题角度裂变法

同一支柱下的话题,用 7 种角度裂变出多个选题——解决"一个话题写完就没得写"。一个母话题可裂变 7-21 个子选题,足够一个月用。

| 角度 | 核心句式 | 产出形态 | 示例(母话题:早起) |
|------|---------|---------|------------------|
| 5W2H | Why/What/How/When… | 系列科普 | 为什么该早起 / 怎样早起不困 |
| 反常识 | 反过来讲 | 观点爆款 | 早起其实毁一天?这类人别试 |
| 对比 | A vs B | 抉择型 | 早起党 vs 熬夜党,谁更高效 |
| 清单 | N 个方法 | 工具型 | 5 个无痛早起法 |
| 故事 | 亲身经历 | 人设型 | 我坚持早起 100 天的变化 |
| 盘点 | 年度/系列 | 合集型 | 早起圈年度 10 大误解 |
| 场景 | XX 时怎么办 | 场景型 | 冬天冷到不想起怎么办 |

裂变工作流:选母话题 → 套 7 角度 → 每角度出 1-3 个选题 → 筛选去重 → 归入支柱与层级。

> 完整裂变表与模板句式详见 `templates/angle-ideation.md`。

### 4. 热点借势

借势是引流的放大器,但乱蹭会伤调性、掉粉。判断一个热点值不值得蹭,用三维评分:

**借势价值 = 相关性 × 速度 × 调性匹配**

| 维度 | 分值 | 评分标准 |
|------|------|---------|
| 相关性 | 0-3 | 热点与你的支柱/定位的关联度。0=纯无关,硬蹭必伤号 |
| 速度 | 0-3 | 发布距热点爆发的时间。黄金 6h / 白银 24h / 之后递减 |
| 调性匹配 | 0-2 | 借势口吻是否符合账号人设(严肃号别玩梗、搞笑号别煽情) |

**总分 ≥ 6 值得蹭;<4 放弃;4-5 看情况(有把握快速产出再蹭)。**

热点分两类:**可预判型**(节日、节气、大促、行业大会)提前 7-14 天储备;**突发型**(社会事件、热搜)靠速度,黄金 6 小时内出手。借势不是复制热搜文案,而是把热点当"钩子",引到你自己的支柱内容上。

> 判断标准与节日/行业事件日历框架详见 `templates/hotspot-calendar.md`。

### 5. 发布时间策略

好选题放错时段等于浪费。各平台活跃时段有规律,引流选题放流量高峰(曝光最大化),深度选题放阅读时段(完读率优先)。

| 平台 | 流量高峰(引流层) | 阅读时段(信任/深度) | 备注 |
|------|------------------|---------------------|------|
| 小红书 | 午休 12-13 / 晚 20-22 | 晚 21-23 | 图文为主,封面定生死 |
| 公众号 | 早通勤 7-9 | 晚 20-22(长文) | 早文重信息,晚文重深度 |
| 抖音 | 午 12-13 / 晚 19-22 | 晚 21-23 | 前 3 秒定留存 |
| 视频号 | 晚 20-22 / 早 7-8 | 晚 20-22 | 社交推荐,重共鸣 |
| B站 | 晚 18-22 | 周末全天 | 中长视频,重干货 |
| 知乎 | 早 8-10 / 晚 20-22 | 晚 21-23 | 长尾搜索流量 |

**跨平台错峰原则**:同一选题多平台改编后,分时段错峰发布(如早公众号、午小红书、晚抖音),避免自我流量竞争,也能吃满各平台高峰。

### 6. 平台差异化改编

一鱼多吃不是复制粘贴。同一选题在不同平台形态不同,把核心论点提取出来按平台重写,而非搬运。

| 平台 | 内容形态 | 篇幅 | 核心钩子 | 改编重点 |
|------|---------|------|---------|---------|
| 小红书 | 图文种草 | 短 | 视觉+标题 | 封面图 + 短正文 + 话题标签 |
| 公众号 | 深度长文 | 长 | 观点+干货 | 结构化 + 金句 + 案例 |
| 抖音 | 短口播/剧情 | 15-60s(新号起步) / 1-3min(成熟号) | 前 3 秒钩子 | 节奏快 + 反转 + 口播稿 |
| 视频号 | 温情/干货 | 30-90s | 共鸣点 | 真诚 + 正能量 + 社交话术 |
| B站 | 中长视频 | 5-15min | 信息密度 | 体系化 + 玩梗 + 互动 |

> 抖音时长说明:前 3 秒定留存,时长随账号权重与完播率数据逐步放开——新号先用 15-60s 拿完播率,数据稳定后再往 1-3min 延伸。

改编映射四步:**①提取核心论点 → ②定平台形态 → ③重写钩子 → ④补平台专属元素(标签/封面/口播稿)**。

## 工作流程

执行时严格按 Step 0→6 顺序,不要跳步。用户没给的输入要主动追问;追问不到的,用合理默认值并在产出里标注"默认假设"。

**Step 0 解析输入**
读取参数:赛道 / 平台 / 账号定位 / 周期(周 or 月)/ 当前阶段(起号/增长/变现)。缺项先追问;定位模糊的,先用"我是谁 + 读者要什么"两句引导用户说清。读 `_config.json`(若存在)补全默认支柱、配比、发布时间偏好。

**Step 1 定内容支柱**
从账号定位推导 3-5 个内容支柱(公式见方法论 2)。已有支柱的账号直接复用;新号用 `templates/pillar-template.md` 画布生成。支柱定下后全程不变(除非用户要调定位)。

**Step 2 按阶段定三层配比**
按当前阶段查方法论 1 的配比表,计算周期内各层选题名额。例如一周 7 篇、增长期 → 引流 4 / 信任 2 / 转化 1。把名额分配到日期格子。

**Step 3 选题发散(角度裂变)**
每个支柱下选 1-2 个母话题,用 `templates/angle-ideation.md` 的 7 角度裂变出候选选题池,再按三层配比挑出本周期要用的选题。挑题标准:与支柱强相关 + 角度不重复 + 有明确目标层级。母话题优先选"读者最近在问的""评论区高频词""行业新趋势",避免自嗨式选题。裂变后先超量产出(候选数 = 需求数 ×1.5),再筛选,留余地应对临时调整。

**Step 4 匹配发布时间 + 平台(含跨平台改编)**
按方法论 5 的时段表,把引流选题放高峰、深度选题放阅读时段。涉及多平台的选题,按方法论 6 做改编映射,标注各平台发布时段。输出填入 `templates/topic-matrix.md`。改编时先提取"核心论点一句话",再按平台形态重写钩子与正文,严禁直接搬运——同文案跨平台会被判定抄袭/限流。

**Step 5 热点借势**
先**优先用用户提供的本周热点来源**——中文平台(WebSearch 为 US-only,对中文热搜覆盖弱)的真实热点应从这些渠道捞:微博热搜、抖音热榜、小红书热点、千瓜 / 新榜 / 飞瓜等第三方数据平台、巨量算数 / 蒲公英等官方工具,或直接请用户粘贴本周热点清单。WebSearch 仅用于两件事:① 可预判型节日 / 节气 / 大促 / 行业大会的当年准确日期核实;② 补充查国际或英文热点。拿到候选热点后,每个用方法论 4 的三维评分筛一遍(≥6 才蹭),把通过的热点选题插入矩阵,替换或补充对应的引流层名额。可预判热点标注"提前 X 天产出"。

**Step 6 输出选题矩阵表 + 内容支柱清单**
最终交付两样:① 选题矩阵表(日期 / 选题 / 角度 / 支柱 / 层级 / 平台 / 时段 / 预期目标);② 内容支柱清单(支柱名 + 定位 + 典型选题方向)。矩阵表用 `templates/topic-matrix.md` 格式,保证可直接复制到飞书/Notion/表格排期。

## 快速上手示例(美妆 / 小红书 / 一周 / 增长期)

以下是完整跑一遍 Step 0→6 的样例,供对照产出形态。

- **Step 0 输入**:赛道=美妆,平台=小红书,周期=一周,阶段=增长期,定位="成分党护肤博主,帮敏感肌避坑选品"。
- **Step 1 支柱**(定位 ∩ 读者需求):① 护肤科普(求知)② 产品测评(求证)③ 成分避坑(求证)④ 好物清单(求用)。4 个支柱,符合 3-5 区间。
- **Step 2 配比**:增长期 5:3:2,一周 7 篇 → 引流 4 / 信任 2 / 转化 1。
- **Step 3 发散**:母话题"换季护肤",套 7 角度裂变出候选(场景:换季爆痘急救 / 反常识:别在换季猛刷酸 / 清单:5 个平价修护单品…)。
- **Step 4 时段**:引流放午 12:00 / 晚 20:00;深度干货放 21:30(阅读时段)。
- **Step 5 借势**:换季属可预判热点(每年固定周期),用 WebSearch 核实当年准确换季时间即可;若用户提供了本周微博/小红书热搜,优先用其补一条突发引流位。本例排一条引流位"换季爆痘别慌"(相关性 3、可预判)。
- **Step 6 产出**:见 `templates/topic-matrix.md` 的示例矩阵表(正是本例的完整排期)。

## 选题质量自检清单

产出交付前,逐条核对。任何一条不过,回去调:

- [ ] 每条选题都挂在某个内容支柱下,没有"孤儿选题"
- [ ] 三层配比符合当前阶段(引流/信任/转化,偏差 ≤±10%)
- [ ] 每个支柱本周至少 1 篇,无支柱整周空白
- [ ] 角度无重复(读者一眼能区分两条选题的差异)
- [ ] 引流选题放流量高峰、深度选题放阅读时段
- [ ] 每条选题有明确的预期目标(涨粉/收藏/咨询…),可量化
- [ ] 借势选题通过三维评分(≥6),无硬蹭
- [ ] 多平台选题做了改编映射,不是复制粘贴
- [ ] 小红书选题附了封面文案建议(图上字 + 构图方向)

## 选题灵感来源(母话题从哪找)

母话题质量决定整张矩阵的天花板。Step 3 发散前,优先从这几个渠道捞母话题,而不是凭空想:

| 来源 | 怎么用 | 产出特点 |
|------|-------|---------|
| 评论区 / 私信高频问题 | 翻近 30 天评论,提炼"被反复问的问题" | 强相关、自带需求验证 |
| 平台搜索联想词 | 输入支柱关键词,看下拉联想 | 算法验证的流量词 |
| 同行爆款拆解 | 找同赛道近期高赞,拆它的角度与缺口 | 找差异化切口 |
| 行业报告 / 数据榜单 | 查赛道季度趋势报告 | 趋势型、有数据背书 |
| 客户/学员真实案例 | 把交付中遇到的共性问题提炼 | 人设化、抄不走 |
| 自身经历复盘 | 季度/年度复盘里的转折点 | 强人设、信任层利器 |

原则:**80% 选题来自有需求验证的渠道(评论区/搜索词/数据),20% 留给创作直觉**。纯靠灵感拍脑袋,选题质量和持续性都会塌方。

## 边界情况与避坑

- **新号没数据,时段靠猜**:方法论 5 的时段表是行业大盘规律,新号第一条建议先在 2-3 个时段各试一次,2 周后用后台数据校准自己的真实高峰,别迷信通用表。
- **配比不是死的**:默认配比是起点,不是教条。大促周(双 11/618)转化层可临时拉到 50%+;行业淡季引流层可上调。配比服务目标,目标变了配比就变。
- **借势翻车高发区**:社会悲剧/灾难/政治敏感事件——相关性再高也别蹭,调性风险 > 流量收益。争议性热点蹭之前先问"这个立场我会不会翻车",不确定就不蹭。
- **中文热点数据源别只靠 WebSearch**:本 skill 的 allowed-tools 含 WebSearch,但它是 US-only,对微博热搜 / 抖音热榜 / 小红书热点 / 巨量算数等中文实时热搜覆盖很弱。跑美妆 / 职场 / 母婴等中文赛道时,Step 5 的热点必须优先来自用户粘贴的中文来源或第三方数据平台(千瓜 / 新榜 / 飞瓜),否则借势环节会形同虚设——这是中文自媒体落地最常踩的坑。
- **角度裂变会重复**:7 角度套多了会出现近似选题(如"为什么早起"和"早起有什么用")。去重原则:标题读者一眼分不出差异的,合并或删一个。
- **多账号矩阵别用同一套选题**:同一公司多个账号同质化会被平台限流。各账号支柱要有差异化(哪怕同赛道,人设/读者层不同),选题池分开维护。
- **小红书封面比选题重要**:再好的选题,封面拉胯也没曝光。引流层选题产出时,顺手给一句封面文案建议(图上字 + 构图方向),别只给标题。
- **AI 生成选题的同质化陷阱**:本 skill 产出的选题若直接照搬,会和同赛道其他 AI 用户撞题。务必用账号独有的经历/数据/客户案例做"人设化"改写——这是抄不走的部分,也是账号护城河。
- **周期太长(月历)准确度下降**:月历的热点借势只能覆盖可预判型(节日/大促),突发热点需每周滚动更新。月历产出后,建议每周末用 Step 5 复盘并微调下周。
- **起号期别急着铺转化层**:粉丝 <1000 时发硬广/产品种草,转化率极低且易掉粉。起号期信任层也先做"人设故事+轻干货",重产品类内容等增长期再上。

## 配置

可选读取项目根目录或 `content-calendar/` 下的 `_config.json`。用户不提供就不创建,全部用默认值。

| 字段 | 类型 | 说明 | 缺省 |
|------|------|------|------|
| `track` | string | 赛道,如"美妆""职场" | 从 argument 推断 |
| `platforms` | string[] | 目标平台列表 | ["小红书"] |
| `account_position` | string | 账号定位一句话 | 追问 |
| `stage` | enum | `起号` / `增长` / `变现` | `增长` |
| `period` | enum | `周` / `月` | `周` |
| `posts_per_week` | number | 每周发文名额 | 7 |
| `ratio` | object | 自定义三层配比覆盖默认 | 按阶段查表 |
| `pillars` | string[] | 已有内容支柱(复用) | Step 1 推导 |
| `peak_hours` | object | 自校准的各平台真实高峰 | 用方法论 5 默认表 |
| `taboo_topics` | string[] | 不碰的话题(合规/调性) | 空 |

读取优先级:argument 显式参数 > `_config.json` > 本 skill 默认值。任何用到默认值的地方,在产出里标注"(默认)",提示用户可校正。

# 限流词 / 违规词 / 广告法敏感词清单

小红书对违规词**没有系统提示**——笔记被限流了你只会以为"内容不行",其实是某个词触雷。本清单用于 Step 5 自检,扫描标题+正文+标签,命中即替换或删除。发布前必过。

---

## 一、绝对化词(广告法明确禁止)

平台和广告法都禁止使用绝对化、排他性表述,命中即限流,严重者违规。

| 命中词 | 替换建议 |
|--------|----------|
| 最 / 最好 / 最佳 / 最强 | 口碑很好 / 表现突出 / 很受欢迎 |
| 第一 / 排名第一 / 销量第一 | 名列前茅 / 热门之选 |
| 唯一 / 独一无二 | 少见 / 颇具特色 |
| 国家级 / 世界级 / 顶级 | 知名 / 业内认可 |
| 永远 / 100% / 绝对 | 个人体验 / 大概率 |
| 之首 / 之王 / 之最 | 值得关注 / 表现亮眼 |

## 二、医疗/功效承诺词(高风险)

美妆、保健、母婴赛道重灾区。即使是个人分享,也不能做疗效承诺。

| 命中词 | 替换建议 |
|--------|----------|
| 根治 / 治愈 / 疗效 | 改善 / 缓解(个人体验) |
| 药到病除 / 包治 | 无对应——直接删除 |
| 祛斑 / 祛痘 / 抗衰(医疗语境) | 淡化 / 改善(护肤语境) |
| 降血压 / 降血糖 / 减肥 | 辅助调节 / 个人体感(加"不构成专业建议") |
| 立竿见影 / 见效快 | 坚持使用有改善 |
| 处方 / 药用 | 成分护肤 / 日常护理 |
| 水光针 / 热玛吉 / 线雕等医美项目(不含"玻尿酸"作为普通护肤成分的提及) | 改为个人体验分享,不做效果承诺;正文加免责声明("仅分享个人体验,医美项目需咨询正规机构,不构成专业建议")。此类内容平台通常要求发布者具备相应资质,普通博主讲效果易限流 |
| 玻尿酸(作为注射类医美项目,如"打玻尿酸") | 按上述医美项目规则处理:改为个人体验分享,不做效果承诺,正文加免责声明 |

> 美妆/保健类正文建议统一加一句:"以上为个人使用体验,不构成专业医疗或护肤建议。"
>
> "玻尿酸"作为普通护肤成分(如"玻尿酸精华""含玻尿酸")可正常使用,不属医美项目;仅当指代注射类项目(如"打玻尿酸")时按医美规则处理。

## 三、导流词(触发降权)

小红书严打站外导流,命中会大幅降权甚至限流。

| 命中词 | 处理方式 |
|--------|----------|
| 加微信 / 加V / 微信号 | 删除,改成"主页有更多分享" |
| 私信领 / 私信我 / DD | 删除,改成"评论区交流" |
| 关注领 / 关注回复 | 删除关注诱导,保留正常内容 |
| 淘宝/拼多多/京东链接 | 删除,带货走平台商品挂载 |
| 扫二维码 / 长按识别 | 删除 |
| 咨询 / 报价 / 代理 | 软化为"分享体验",去除交易暗示 |

## 四、虚假/夸大数据词

无出处或无法核实的数据,平台会判定虚假信息。

| 命中词 | 处理方式 |
|--------|----------|
| 99%的人不知道 | 删除或改成"很多人可能没注意" |
| 销量10万+ / 好评如潮(无依据) | 删除,或标注具体来源 |
| 月入过万 / 日入千元(无实证) | 删除或改为"我的真实收入是XX" |
| 全网最低 / 史无前例 | 删除(兼属绝对化词) |

## 五、低质营销词(影响权重)

不算违规,但会拉低内容质量分,导致推荐量下降。

| 命中词 | 替换建议 |
|--------|----------|
| 震惊 / 惊呆了 / 吓死 | 真实感受:没想到 / 挺意外 |
| 必买 / 不买后悔 | 值得考虑 / 个人会回购 |
| 神器 / 神仙水 / 救命 | 很好用 / 挺惊艳(去标签化) |
| 居家必备 / 人手一个 | 适合XX人群 / 我自己一直在用 |
| 姐妹们冲 / 闭眼入 | 感兴趣可以了解下 / 我自己入了 |

---

## 自检执行规则

1. 扫描范围:标题 + 正文 + 标签,三者都要过。
2. 命中绝对化/医疗/导流词:**必须替换或删除**,不可保留。
3. 命中夸大数据:删除或补来源,无法核实就删。
4. 命中低质营销词:建议替换,用户坚持可保留但提示风险。
5. 自检结果在输出中列出("已替换:XX→XX"),让用户知道改了什么、为什么改。
6. 命中医疗类且赛道为美妆/保健/母婴:正文统一补一句免责声明。

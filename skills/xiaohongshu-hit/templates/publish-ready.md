# 可复制发布版排版模板

Step 6 按本模板输出最终成稿。分块清晰,用户复制即用,不需要二次整理。以下为格式骨架 + 一个完整示例。

---

## 输出格式骨架

```
═══════════════════════
🔍 市场校准状态(必填,不可省略 —— 见 SKILL Step 1.5)
═══════════════════════
[三选一,逐字保留图标 + 措辞]
✅ 已做实时市场校准(基于近30天 X 篇高赞笔记)
   或
⚠️ WebSearch 失效,本次基于兜底句式表 / 用户参考笔记做离线校准,标题/标签非实时数据
   或
❌ 本次未做市场校准(实时检索失效 + 无兜底数据),标题/标签基于默认公式
[一句话说明来源:参考了 fallback 表 / 用户 X 篇参考笔记 / 默认公式]

═══════════════════════
📌 标题(已选定)
═══════════════════════
[用户选定的标题]

═══════════════════════
📝 正文(可直接复制)
═══════════════════════
[完整 emoji 排版正文]

═══════════════════════
🏷️ 话题标签
═══════════════════════
#大词 #中词1 #中词2 #长尾1 #长尾2 #长尾3

═══════════════════════
🖼️ 封面文案 + 视觉建议
═══════════════════════
主标题(建议8-10字):XXX
副标题:XXX
视觉建议:色调/构图/是否出镜

═══════════════════════

═══════════════════════
- 建议发布时间
- 配图数量与顺序
- 互动话术
- 限流词自检结果(已替换:XX→XX)
```

> 「市场校准状态」块**必须出现在交付物最顶部、标题区之前**。它是 Step 1.5 卖点兑现与否的诚实声明:WebSearch 失效时不能让用户以为拿到了"看着市场写"的成果。三种措辞固定,逐字保留图标(✅/⚠️/❌)便于扫读。

## 完整示例(主题:敏感肌平价水乳推荐)

```
═══════════════════════
🔍 市场校准状态
═══════════════════════
✅ 已做实时市场校准(基于近30天 4 篇高赞笔记)
来源:WebSearch "敏感肌水乳 小红书 爆款 近30天",标题优先套用句式①⑤,标签替换过气大词 #平价护肤 → #敏感肌护肤。

═══════════════════════
📌 标题(已选定)
═══════════════════════
5个百元内水乳,敏感肌亲测不踩雷

═══════════════════════
📝 正文(可直接复制)
═══════════════════════
换季一烂脸,钱包就开始疼😢
试过一堆水乳,要么刺激要么贵,敏感肌真的太难了。

后来死磕成分,把市面上百元内的水乳扒了一遍,
总结出这5款,亲测温和不踩雷👇

✨ 神经酰胺修护水
主打修护屏障,上脸不刺痛,烂脸期靠它稳住
每瓶不到80,学生党友好

✨ 燕麦舒缓乳
换季泛红用它,厚敷一晚第二天明显退红
无酒精无香精,成分表干净

✨ 积雪草水
清爽不黏,油敏皮夏天也能用
当化妆水湿敷,镇定效果一绝

✨ 角鲨烷乳
干敏皮锁水刚需,轻薄不闷痘
搭配同系列水,一套百元出头

✨ 泛醇修护乳
晒后修复+日常维稳,一支多用
药房常推的成分,温和度有保障

说实话敏感肌选水乳,别迷信贵的,
看成分(神经酰胺/积雪草/泛醇/角鲨烷)比看价格靠谱。

你们换季都用什么水乳?评论区抄个作业👇
觉得有用求赞藏,下期出身体乳合集~

═══════════════════════
🏷️ 话题标签
═══════════════════════
#美妆护肤 #敏感肌护肤 #平价水乳 #学生党护肤 #换季烂脸 #百元内水乳

═══════════════════════
🖼️ 封面文案 + 视觉建议
═══════════════════════
主标题:敏感肌水乳亲测榜(8字)
副标题:5款百元内·亲测不踩雷
视觉建议:奶油白底色,5款产品居中排列,主标题大字黑体置顶,副标题小字底部;无需出镜,产品实拍即可。

═══════════════════════
💡 发布小贴士
═══════════════════════
- 发布时间:工作日 12:00-13:00 或 20:00-22:00(美妆活跃时段)
- 配图:封面1张 + 每款产品特写1张 + 成分表截图1张,共6-7张
- 互动话术:评论区主动回复前10条,提升初始互动权重
- 限流词自检:已将原"最好用"→"亲测温和"、"闭眼入"→"亲测"、"神器"→"刚需";其余无命中
- 商业合作提醒:如为品牌合作,请在发布时开启"赞助"标注
```

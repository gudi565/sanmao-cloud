# 小红书爆款笔记

> 输入主题,产出一篇可直接复制发布的小红书成稿——标题、正文、标签、封面文案全部到位。

## 这是什么

这是一个封装了小红书爆款方法论的生产工具,不是"帮你写点灵感"的助手。它把写笔记这件依赖经验和手感的事,拆成 7 步可复用流水线:选题解析 → 匹配赛道 → 标题生成 → 正文撰写 → 标签配比 → 限流词自检 → 发布版输出。最终交付物是一份分块清晰、复制即用的成稿,而不是半成品。

## 30 秒上手

1. **安装**:把整个 `xiaohongshu-hit/` 文件夹放到 `~/.claude/skills/` 下(或项目级 `.claude/skills/`)
2. **调用**:在 Claude Code 里输入 `/xiaohongshu-hit <你的主题>`
3. **拿结果**:按分步流程产出成稿,标题正文标签封面一次性给齐

```
/xiaohongshu-hit 敏感肌平价水乳推荐
/xiaohongshu-hit XX品牌神经酰胺水乳种草带货
```

## 它能帮你做什么

- **一次生成 5 个差异化标题候选**,来自爆款标题 7 公式(数字承诺/悬念/对比/反常识/共情/清单/结果),覆盖至少 4 种心理触发点,不再只给一个"我觉得不错"
- **按"痛-干-真"结构写正文**:钩子承接标题、痛点引发共鸣、干货分点可截图收藏、真诚总结建立信任、互动引导拉升数据
- **匹配 8 大主流赛道调性**:美妆/穿搭/母婴/数码/职场/美食/旅游/学习,每个赛道的语气、侧重段落、避坑点都有速查表
- **话题标签 3 层配比**:1 大词 + 2 中词 + 3 长尾,让算法精准归类,避免只堆大词被淹没
- **发布前限流词自检**:扫描绝对化词、医疗承诺、导流词、虚假数据、低质营销词五类雷区,命中即替换并列出结果
- **可选爆款校准**:联网搜近 30 天高赞笔记的标题钩子和高频标签,让选题对齐当下市场,而非凭感觉

## 适合谁

- **小红书博主**:日常更新想不出标题、正文完播率低、标签乱挂一通
- **品牌种草/投放团队**:素材要批量生产、调性要统一、还要过限流自检
- **MCN 和带货卖家**:需要可复制的产出流程,而不是每个博主各写各的
- **本地商家/冷启动新号**:不懂平台规则,需要一套兜底的合规写法

## 包含什么

- `SKILL.md` — 主文件(约 240 行):6 条核心方法论 + 7 步工作流 + 10 项交付前自检清单
- `templates/title-formulas.md` — 爆款标题 7 公式,每公式配真实示例和适用场景
- `templates/niche-templates.md` — 8 赛道调性/侧重/避坑速查表,写之前先锁调性
- `templates/limited-words.md` — 5 类限流词清单 + 替换建议,发布前必过
- `templates/publish-ready.md` — 可复制发布版分块模板,含完整示范

(`LISTING.md` 是市场上架文案,日常使用可忽略。)

## 常见问题

- **要不要联网?** 不联网也能完整跑完全流程。Step 1.5 的"爆款校准"会联网搜近 30 天高赞笔记做选题对齐,属于推荐项;无网络或无权限时自动跳过,走默认公式。
- **能不能自定义?** 可以。在项目根目录放一个 `_config.json` 就能调默认赛道、语气、emoji 密度、字数、标签数量等(字段见下节)。不提供则走默认值,开箱即用。
- **支持什么平台/语言?** 仅针对小红书(图文为主、移动端、强种草),中文内容。同样内容发抖音或公众号需要改写,不能直接套用。

## 配置(可选)

在项目根目录创建 `_config.json` 即可自定义,无需配置也能开箱即用。关键字段:

| 字段 | 默认值 | 说明 |
|------|--------|------|
| `default_niche` | 无 | 默认赛道,如"美妆",省去每次指定 |
| `tone` | "真诚种草" | 整体语气:真诚种草 / 专业测评 / 闺蜜安利 |
| `emoji_density` | "medium" | emoji 密度:low(6-8)/ medium(8-12)/ high(10-12,仅视觉类赛道) |
| `word_count` | "400-800" | 正文字数区间 |
| `tag_count` | 6 | 话题标签数量,5-8 |
| `brand_words` | [] | 品牌必带词,如 `["成分","无添加"]` |
| `forbidden_words` | [] | 额外想避开的词 |

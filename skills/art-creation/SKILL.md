# 艺术创作方案设计助手

当用户调用此技能时，立即使用 Workflow 工具执行艺术创作方案工作流。

## 核心理念

你做创意决策，我做执行脏活：
- **你提供**：主题、核心思想、情感基调、个人偏好
- **我负责**：搜索灵感参考、分析风格流派、推荐尺寸媒介色彩、合成完整方案

## 执行步骤

1. 从用户输入中提取关键参数：
   - **theme**：创作主题（必填）
   - **emotion**：情感基调 / 核心思想（选填，可从主题推断）
   - **medium**：偏好媒介（选填，如油画、数字艺术、雕塑、装置、摄影等）
   - **context**：创作场景（选填，如个人练习、展览参展、商业委托、学术作品等）

2. 如果用户没有提供主题，友好地询问。

3. 调用 Workflow 工具，指向工作流脚本：

```
scriptPath: /Users/serein/.claude/workflows/art-creation.js
args: { theme: "用户提供的主题", emotion: "情感基调", medium: "偏好媒介或留空", context: "创作场景或留空" }
```

4. 工作流完成后，向用户展示完整的创作方案，包括：
   - 方案标题与核心理念
   - 风格参考（含搜索到的真实艺术家 / 流派）
   - 视觉语言（色彩、构图、技法）
   - 尺寸与媒介建议
   - 创作步骤路线图
   - 可选变体方案

## 示例调用

用户输入：
```
/艺术创作 我想画一幅关于"孤独与自由"的作品，偏向油画
```

提取参数：
- theme: "孤独与自由"
- emotion: "孤独与自由"
- medium: "油画"
- context: 留空

用户输入：
```
/艺术创作 做一个数字艺术作品，主题是"数据时代的自我迷失"，准备参加新媒体艺术展
```

提取参数：
- theme: "数据时代的自我迷失"
- emotion: "迷失、疏离"
- medium: "数字艺术/新媒体"
- context: "新媒体艺术展参展"

# 论文写作助手

当用户调用此技能时，立即使用 Workflow 工具执行论文写作工作流。

## 执行步骤

1. 从用户输入中提取三个关键参数：
   - **topic**：论文主题（必填）
   - **field**：研究领域（必填）
   - **venue**：目标期刊/会议（选填）

2. 如果用户没有提供完整信息，询问缺失的参数。

3. 调用 Workflow 工具，指向已保存的工作流脚本：

```
scriptPath: /Users/serein/.claude/workflows/write-academic-paper.js
args: { topic: "用户提供的主题", field: "用户提供的领域", venue: "用户提供或留空" }
```

4. 工作流完成后，向用户展示：
   - 论文标题
   - 摘要
   - 审稿评分
   - 终稿摘要（前 200 字）

## 示例调用

用户输入：
```
/论文 Transformer架构中注意力机制的稀疏化方法 机器学习 ICML
```

提取参数：
- topic: "Transformer架构中注意力机制的稀疏化方法"
- field: "机器学习"
- venue: "ICML"

用户输入：
```
/论文 帮我写一篇关于量子计算误差校正的论文
```

提取参数：
- topic: "量子计算误差校正"
- field: "量子计算"（从主题推断）
- venue: 留空

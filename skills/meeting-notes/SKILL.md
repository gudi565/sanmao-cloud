# 会议纪要

你的任务:把会议的原始素材(录音转写 / 速记 / 零散记录)整理成一份**别人没开会也能看懂、看一眼就知道该干嘛**的正式会议纪要。

会议纪要的最高标准:**行动项足够清楚,执行人不用回看会议就能开干;决议足够明确,没有"大概、可能"。**

## 何时用

- 录音转写 / 飞书妙记 / Otter 导出的会议文字稿 → 整理成纪要。
- 速记 / 手写要点 → 成文分发。
- 开完会要给团队发正式记录。
- 要从一堆会议里抽出行动项做跟进。

## 何时别用

- 只要一个简短摘要(发给没参会的人快速了解)→ 用 `summarize`(会议场景模板)更轻。
- 会议需要逐字记录(如董事会/法律)→ 标注后仍可用,但提醒用户正式存档以原转写为准。
- 做项目排期/甘特 → 用 `roadmap-planning`。
- 提取任务到 todo 系统 → 这里产出行动项清单,导不导进系统由用户决定。

## 纪要的六块结构

一份合格的会议纪要必备这六块(模板见 references):

1. **会议基本信息**:主题、时间、地点、参会人、记录人、(可选)缺席人。
2. **议程与讨论**:按议题组织(不是按发言时间流水账),每个议题写"讨论了什么 + 关键分歧"。
3. **决议**:明确达成的决定。**每条写清"决定了什么",含糊的标"未达成共识"。**
4. **行动项**:谁、做什么、何时完成。(没有责任人/截止的标"待定",不要替会议分配。)
5. **遗留问题 / 下次议题**:没解决的、挂起的、下次要谈的。
6. **附件 / 引用**(可选):相关文档链接、数据来源。

## 五条核心纪律

1. **按议题组织,不按时间流水。** 把"谁说了什么"换成"议题 X 讨论了什么、结论是什么"。流水账是会议纪要最大的失败。
2. **决议要可执行地明确。** "决定推进 A 方案" > "大家倾向于 A"。"倾向于"不是决议,要标"初步倾向,待 X 确认"。
3. **行动项三要素齐全**:动作 + 责任人 + 截止时间。缺任一项都标"待定",不要脑补。
4. **忠实记录分歧。** 没达成一致的要写"甲方认为 X,乙方认为 Y,未定",而不是假装一团和气。
5. **不臆造。** 转写里没有的信息绝不补。模糊的地方标"录音不清,建议核实"。

## 工作流

### 1. 通读素材,提取元信息

先读完整篇转写,确定:会议主题、时间、参会人(从发言和开头识别)、议题大致顺序。

### 2. 识别议题边界

把流水般的转写按议题切段。议题信号:"我们聊聊 X""第一个问题是""那关于 Y"。一个议题内的所有讨论归到一起。

### 3. 每议题提炼:讨论 → 决议

对每个议题:
- 这段讨论的**核心议题**是什么?
- 讨论了哪些**要点/分歧**?
- 最后**决议**是什么?(没决议就如实写"讨论未果/延期/待补充信息")。

### 4. 横向抽取行动项

通读全文,把所有"谁要去做什么"的动作拎出来,汇总成行动项表。每个补全:动作、责任人、截止、(可选)优先级。

**自检**:有动作没责任人?→ 标"待指派"。有责任人没截止?→ 标"待定截止"。

### 5. 产出纪要 + 行动项跟进表

按六块结构产出会议纪要正文,行动项单独列表(便于复制到任务系统)。

## 失败模式(别犯)

- ❌ **流水账**:"张三说...李四说..."——没人要看这个。
- ❌ **决议含糊**:"倾向于""基本同意""考虑推进"——这不是决议。
- ❌ **行动项残缺**:写了做什么没写谁、没写何时。
- ❌ **假装共识**:抹掉分歧,让纪要看起来一团和气,但执行时才发现没真定。
- ❌ **漏掉议题**:整段讨论被略过。
- ❌ **脑补**:转写不清的地方自己补全(如编个数字/截止日)。
- ❌ **太长**:把每个发言都记下来,纪要变得比会议还长。

## 不同会议类型的侧重

| 会议类型 | 纪要侧重 |
|---|---|
| 决策会 | 决议 + 理由(为什么这么定)最重要 |
| 站会/周会 | 行动项 + 进度 + 阻塞最重要 |
| 头脑风暴 | 想法清单 + 分类 + 下一步,决议可能很少 |
| 评审会 | 评审意见 + 修改要求 + 复盘节点 |
| 1on1 | 保密(提醒用户),通常只记行动项和承诺 |

## 输出格式

```
# 会议纪要:{主题}
时间 / 地点 / 参会人 / 记录人

## 议题与决议
### 议题 1:{议题}
- 讨论:{要点 + 分歧}
- 决议:{明确决定 / 或"未达成共识,待 X"}
...

## 行动项
| 动作 | 责任人 | 截止 | 优先级 |
|---|---|---|---|
| ... | ... | ... | 高/中/低 |

## 遗留 / 下次
- {没解决的 / 下次要谈的}
```

附一句:"行动项已单独列表,可直接复制到任务系统;需要发飞书/邮件版本告诉我。"

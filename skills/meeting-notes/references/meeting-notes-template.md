# 会议纪要模板(三种风格 + 范例)

按会议正式程度选模板。填空即用。

---

## 模板 A:正式纪要(跨团队 / 对外 / 管理层)

适合:需要存档、对外分发、决议重要的会议。

```markdown
# 会议纪要:{主题}

| 项 | 内容 |
|---|---|
| 时间 | YYYY-MM-DD HH:MM–HH:MM |
| 地点/方式 | {线下地点 / 线上会议链接} |
| 召集人 | {姓名} |
| 参会人 | {姓名列表} |
| 缺席人 | {姓名}(可选) |
| 记录人 | {姓名} |

## 会议目的
{1-2 句:这次会要解决什么}

## 议题与决议

### 议题 1:{议题名}
- **讨论**:{要点 + 关键分歧,精炼}
- **决议**:{明确决定;未定则写"未达成共识,待 {谁/什么} 后定"}

### 议题 2:{议题名}
- **讨论**:...
- **决议**:...

## 行动项
| # | 动作 | 责任人 | 截止 | 优先级 |
|---|---|---|---|---|
| 1 | {做什么} | {谁} | {日期} | 高/中/低 |
| 2 | ... | ... | ... | ... |

## 遗留问题 / 下次议题
- {没解决的、挂起的、下次要谈的}

## 附件
- {相关文档链接 / 数据来源}
```

## 模板 B:轻量纪要(团队内部 / 日常协作)

适合:组内同步、快速对齐,不需要正式存档。

```markdown
# {主题} · 会议纪要 {日期}

**参会**:{姓名}
**结论先行**:{一句话:这次会最重要产出是什么}

## 决定了什么
- {决议 1}
- {决议 2}

## 谁做什么
- [ ] {谁} — {做什么} — {何时}
- [ ] {谁} — {做什么} — {何时}

## 待定/遗留
- {悬而未决的事}
```

---

## 模板 C:站会 / 周会(高频小会)

适合:每日站会、周同步。重点在行动项和阻塞。

```markdown
# {团队} 站会 {日期}

## 进度
- {人}:{昨天做了什么 / 今天打算}
- {人}:...

## 阻塞 / 需要协调
- {人}卡在 {什么},需要 {谁} 帮 {什么}

## 行动项
- [ ] {谁} — {做什么} — {何时}
```

## 范例:一份填好的正式纪要(节选)

```markdown
# 会议纪要:Q3 增长策略评审

| 项 | 内容 |
|---|---|
| 时间 | 2026-07-30 14:00–15:30 |
| 地点/方式 | 飞书会议 |
| 召集人 | 张三(增长负责人) |
| 参会人 | 张三、李四(产品)、王五(数据)、赵六(市场) |
| 记录人 | 李四 |

## 会议目的
确定 Q3 用户增长的 1-2 个主攻方向及对应预算分配。

## 议题与决议

### 议题 1:主攻方向选型
- **讨论**:市场(赵六)主张加大投放拉新;产品(李四)主张做 referral 裂变提留存;数据(王五)给出测算——裂变 ROI 预估 1:3,投放 1:1.5。
- **决议**:Q3 主攻 referral 裂变(占预算 60%),投放保留但收缩(40%)。裂变方案 8/10 前出详细设计。

### 议题 2:预算分配
- **讨论**:60/40 的具体拆分。
- **决议**:裂变预算 60 万,投放 40 万。若 8 月底裂变 ROI 未达 1:2,9 月回调。

## 行动项
| # | 动作 | 责任人 | 截止 | 优先级 |
|---|---|---|---|---|
| 1 | 输出 referral 裂变详细方案 | 李四 | 2026-08-10 | 高 |
| 2 | 搭裂变数据埋点和看板 | 王五 | 2026-08-15 | 高 |
| 3 | 准备投放收缩后的渠道调整 | 赵六 | 2026-08-20 | 中 |

## 遗留 / 下次
- 裂变涉及合规(诱导分享),需法务确认 —— 李四 8/5 前拉法务。
- 下次评审:8/30,看 8 月数据决定 9 月预算。
```

## 纪要写作纪律速查

- 议题组织,不按时间流水。
- 决议可执行地明确;含糊的标"未定/待 X"。
- 行动项三要素:动作 + 责任人 + 截止;缺的标"待定"。
- 分歧如实记,不抹平。
- 不臆造转写里没有的信息。

# 思维导图拆解维度库 & 范例 & Markmap 增强

## 一、常用 MECE 拆解维度(选对维度 = 成功一半)

拿到一个主题,先想"从哪几个正交维度拆"。下表是高频可复用维度:

| 拆解维度 | 子项示例 | 适用主题 |
|---|---|---|
| 按流程/阶段 | 规划 → 执行 → 验收 → 复盘 | "怎么做"类、生命周期 |
| 按组成/分类 | 前端 / 后端 / 数据 / 运维 | 系统组成、知识领域 |
| 按因果 | 现象 → 原因 → 对策 → 预防 | 分析问题、复盘 |
| 按优先级 | 必须 / 重要 / 可选 / 不做 | 决策、需求分级 |
| 按角色/主体 | 用户 / 商家 / 平台 / 监管 | 多方系统、业务流 |
| 按时间 | 短期 / 中期 / 长期 | 规划、路线图 |
| 按层级 | 战略 / 战术 / 执行 | 组织、目标拆解 |
| 按属性 | 是什么 / 为什么 / 怎么做 | 概念科普 |
| 按场景 | 场景 A / B / C | 产品功能、用例 |
| 按正反/优劣 | 优势 / 劣势 / 机会 / 风险(SWOT) | 评估、选型 |

**选维度的心法**:回到用户的目的。用户要"执行"就按流程拆;要"评估"就按优劣;要"科普"就按是什么/为什么/怎么做。

## 二、四类典型脑图范例

### 范例 1:知识树(科普/学习一个领域)

主题「机器学习」用"按分类 + 按属性"混合:

```
# 机器学习
- 是什么
  - 定义:从数据中学习规律
  - 和传统编程的区别
- 主要类型(按学习方式)
  - 监督学习
    - 分类
    - 回归
  - 无监督学习
    - 聚类
    - 降维
  - 强化学习
- 典型任务
  - 图像识别
  - 自然语言处理
  - 推荐系统
- 常见算法
  - 线性回归 / 决策树 / 神经网络
- 学习路径(按阶段)
  - 入门:数学基础 + scikit-learn
  - 进阶:深度学习框架
  - 实战:Kaggle 项目
```

### 范例 2:项目拆解(执行型)

主题「上线一个新功能」用"按流程":

```
# 上线功能 X
- 需求与设计
  - 需求评审
  - 技术方案
  - 接口设计
- 开发
  - 前端
  - 后端
  - 联调
- 测试
  - 单测
  - 集成测试
  - QA 验收
- 发布
  - 预发验证
  - 灰度
  - 全量
- 复盘
  - 监控指标
  - 问题回顾
```

### 范例 3:决策树(选择型)

主题「该不该用 X 技术栈」用"按评估维度":

```
# 选型:前端框架
- 评估维度
  - 团队熟悉度
    - 现有能力
    - 学习成本
  - 生态成熟度
    - 组件库
    - 社区支持
  - 性能需求
    - 首屏速度
    - 包体积
  - 长期维护
    - 迭代活跃度
    - 招人难度
- 候选
  - React
  - Vue
  - Svelte
- 结论与风险
```

### 范例 4:读书笔记(从书做脑图)

抓作者章节结构为骨架,补漏删冗:

```
# 《X》读书笔记
- 核心论点(一句话)
- 第一部分:问题
  - 作者指出现状是什么
  - 为什么是问题
- 第二部分:原因
- 第三部分:方案
- 我的启发
  - 可迁移的点
  - 不同意的地方
```

## 三、Markmap 语法增强(让脑图更好看)

标准 markdown 缩进在 [markmap.js.org/repl](https://markmap.js.org/repl) 粘贴即可成图。增强语法:

### 节点高亮 / 加粗 / 颜色
用 markdown 内联:
```
- **重要节点**(加粗)
- `代码风格`(等宽)
- [文本](链接)(可点击)
-普通节点
```

### 用 HTML 控制颜色(Markmap 支持)
```
- <span style="color:red">高风险</span>
- <span style="color:green">已完成</span>
```

### 折叠(Markmap 自动按层级可折叠,无需特别标记)

### 加图标(用 emoji 作为视觉标记,简单有效)
```
- ✅ 已完成
- 🚧 进行中
- ⚠️ 有风险
- 💡 关键点
```

## 四、XMind / 幕布 导入提示

- **XMind**:文件 → 导入 → Markdown,直接吃 markdown 缩进。
- **幕布**:直接粘贴 markdown 列表,自动成大纲(幕布本身就是大纲→脑图)。
- **MindNode / iThoughts**:多数支持 markdown 或 OPML 导入。
- **飞书文档**:粘贴列表后可一键转思维导图。

## 五、MECE 自检清单

- [ ] 同层节点两两不重叠?
- [ ] 同层节点合起来覆盖了父节点全部?
- [ ] 同层节点处在同一分类维度?
- [ ] 深度是否 3-4 层(没有碎成 6 层)?
- [ ] 节点是短语不是长句?

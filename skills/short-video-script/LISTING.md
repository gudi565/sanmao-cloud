# 短视频脚本工厂 Short Video Script Factory
> 3 秒留人，完播带货，照着就能拍

## 🎯 一句话介绍

不是"帮你写段口播",是把你给的「主题 + 形式」变成一份**拍摄现场照着就能拍**的成稿脚本。它封装的不是灵感,而是完播率结构、黄金 3 秒钩子公式、口播节奏量化、分镜拆解这套可复用的工业化 SOP——所以即使你不是创意型选手,也能稳定产出 70 分以上、算法爱推的脚本。每一份输出都强制过**钩子 A/B / 完播结构校验 / 口播字数核对 / 景别多样性检查**四道关,拿到就能直接交付拍摄。

- **MCN 脚本岗 / 代运营**：要批量、稳定交付能过审的脚本，靠灵感出活太慢、质量飘忽。
- **本地商家（探店 / 引流）**：不懂短视频拍摄，只想要一份"对着念、对着拍"就能发的脚本。

## ✨ 核心卖点

- **默认给 3 个钩子候选，而不是 1 个** —— 前 3 秒决定 80% 完播，钩子必须 A/B 测试。基于 6 大公式各产 1 个并标注强度（1-10），你选最稳的那个，命中率比"赌一个"高得多。
- **封装的是"完播率结构"，不是灵感** —— 明确要求每 15-20 秒一个转折/新钩子、中段价值密度必须最高、CTA 前留情绪锚点。这是"算法为什么推你"的结构化判断，照着填就不会"开头精彩中间塌方"。
- **口播逐字稿有量化红线** —— 单句 ≤15 字、每 30 秒 80-100 字、强制标注停顿（/）和重音（加粗）。念着不卡壳、主播不用喘，杜绝"45 秒塞 200 字念不完"的常见翻车。
- **抖音 / 视频号 / 快手调性全内置** —— 同一脚本直接换平台发大概率扑街。这里把三平台节奏、钩子风格、人群、BGM、CTA 差异和跨平台改写规则全部沉淀好，一份选题能正确降维成三个版本。
- **四种视频形式独立骨架，不套同一模板** —— 知识口播、剧情演绎、好物种草、口播+混剪各有各的完播结构，先定形式再填内容，避免"一套模板套所有视频"的平庸。
- **全中文 + 本土场景，开箱即用** —— 市面上英文 short-video skill 多、对国内平台水土不服；这个为抖音/视频号/快手创作者写，示例全是敏感肌护肤、减脂餐、本地探店、母婴育儿这类本土选题，还内置了三平台的违规雷区清单（绝对化用语、医疗疗效词、站外导流等会被限流的坑）。

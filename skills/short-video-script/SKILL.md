# 短视频脚本工厂

把一个"主题 + 形式"的需求,变成一份**拍摄现场照着就能拍**的短视频脚本。这个 skill 解决三件事:① 开头 3 秒让人不划走;② 中段让人看到结尾(完播);③ 结尾让人点赞、关注、评论、下单。它封装的不是"写文案的灵感",而是**完播率结构 + 钩子公式 + 口播节奏 + 分镜拆解**这一套可复用的工业化 SOP,所以即使你不是创意型选手,也能稳定产出 70 分以上的脚本。

什么时候用:接到一个拍摄需求(带货、涨粉、种草、引流)、自己起号需要批量出脚本、给主播/MCN 交付脚本、把一篇图文或一个产品改造成短视频。

## 核心方法论

下面六条是这个 skill 的"值钱部分"。每一条都是**带理由的判断**,不是口号。对应可复用模板见 `templates/`。

### 一、黄金 3 秒钩子:决定 80% 的完播

前 3 秒是抖音/视频号算法判断"推不推"最关键的依据之一(叠加点击率、互动率、停留时长等多指标综合权重,但 3 秒留存是地基)。一个视频能不能爆,钩子定 8 成。**钩子不是标题党,是"一句话制造信息差"**——让观众觉得"这个我不知道 / 这跟我以为的不一样 / 这对我有用,我得听完"。本 skill 默认给 3 个钩子候选,而不是 1 个,因为钩子需要 A/B 测试,单一钩子命中率低。六类公式见 `templates/hook-formulas.md`。

> 判断标准:把钩子单独读出来,如果"停下来想知道答案"的冲动低于 7 分(满分 10),换。

### 二、完播率结构:每 15-20 秒一个"新钩子"

完播率 = 看到结尾的人 ÷ 点开的人。算法对完播率高的视频权重最大(综合完播率 + 互动率 + 停留时长 + 点击率等多指标,但完播率是核心杠杆)。**"开头精彩 + 中间平铺直叙"是最大的翻车点**——观众在第 8 秒划走。正确的结构是:开头大钩子之后,**每隔 15-20 秒再抛一个小钩子或转折**,让观众的"想看完"的冲动一直续命;中段(视频的 40%-70%)价值密度必须最高,因为这里最容易流失;结尾 CTA 之前留一个**情绪锚点**(一句共鸣/一个反转),把观众"粘"到最后一秒。

3-5 个情绪点的标准曲线:**好奇 → 认同 → 惊喜 → 信任 → 行动**。少于 3 个会平淡,多于 5 个会散。

```
完播率时间轴(以 45s 视频为例)
0-3s   ▓▓▓ 大钩子(提问/冲突/反常识)——决定推量
3-15s  ▓▓  铺垫价值,给"看下去的理由"
15-20s ▓   第一转折/新钩子(防流失)
20-35s ▓▓▓ 价值密度峰值(干货/反转/高潮)
35-40s ▓   情绪锚点(共鸣/信任)
40-45s ▓   CTA(点赞/关注/下单)+ 评论区钩子
```

### 三、口播逐字稿:短句、口语、有呼吸

口播稿不是文章,是"说出来的话"。核心矛盾是:**书面语让观众的大脑多一道翻译工序,翻译不过来就划走**。所以规则是反直觉的——能用短句绝不用长句,能用大白话绝不用书面词。

量化规范(必须遵守):

| 维度 | 标准 | 反例 |
|------|------|------|
| 单句字数 | ≤ 15 字(超 20 字必须拆) | "对于敏感肌来说在选择护肤品的时候需要注意成分" |
| 节奏 | 每 2-3 句标一个停顿(/)或重音(**加粗**) | 一口气念到底 |
| 语速 | 每 30 秒 80-100 字(快口播 110-120) | 30 秒塞 150 字 |
| 用词 | 口语、短词、动词优先 | "进行一个XX的操作""具有XX的特性" |
| 结构 | 禁止长定语前置 | "一款含有烟酰胺和神经酰胺的适合敏感肌的精华" |

### 四、四种视频形式:先定形式,再填结构

不同形式的完播结构不同,**不能一套模板套所有视频**。本 skill 支持四种,每种有独立的结构模板见 `templates/script-formats.md`:

1. **知识口播**:口播 + 字幕 + 素材画面。结构 = 钩子 → 结论先行 → 分点论证(通常 3 点) → 总结 + CTA。涨粉、知识付费主力形式。
2. **剧情演绎**:角色 + 冲突 + 反转。结构 = 场景设定 → 冲突爆发 → 反转/解决 → 价值观升华。吃剧情流量,但脚本门槛最高。
3. **好物种草**:痛点 → 产品 → 体验 → 效果。结构 = 共鸣痛点 → 抛出产品 → 拆解卖点(场景化) → 效果展示 + 促单。带货/种草主力。
4. **口播 + 素材混剪**:节奏快、信息密度高,口播为骨架,素材(产品图/网图/录屏)填画面。适合没有真人出镜条件、又想快节奏的账号。

### 五、平台调性差异:同一条脚本换个平台可能完全不推

三大平台的人群、审美、算法偏好差异极大。**把抖音脚本直接发视频号,大概率扑街**。核心差异见 `templates/platform-tones.md`:

| 平台 | 节奏 | 钩子风格 | 人群 | BGM | 信任来源 |
|------|------|----------|------|-----|----------|
| 抖音 | 快(前 3 秒定生死) | 强冲突、反常识、热点 | 18-35 主力,爱新鲜 | 热点卡点 BGM | 人设/爽感 |
| 视频号 | 中慢(可铺垫) | 温情、价值观、故事 | 35+,中老年多 | 舒缓、抒情 | 真实、熟人、价值观 |
| 快手 | 中 | 接地气、老铁话术 | 下沉市场 | 乡土、流行 | 真实、人味 |

### 六、CTA 与评论区钩子:拉升互动率的最后一步

点赞、评论、收藏、关注——这四个动作直接进算法推荐池。**结尾 CTA 不能是"记得点赞关注"这种废话**(观众已免疫),要给一个"做了就有好处"或"不吐不快"的理由。四类范式,按视频目标选:

- **利益型 CTA**:"评论区扣 1,我私信你一份敏感肌成分避雷表。"
- **争议型 CTA**:"你觉得 XX 到底是不是智商税?评论区聊聊。"——制造对立拉升评论率。
- **收藏型 CTA**:"这条建议收藏,下次买护肤品对照着看。"——收藏率高,算法判定干货。
- **涨粉/关注型 CTA**(目标=涨粉时**必选**,光喊"点个关注"观众无感,要给关注一个理由):
  - 关注 + 领资料:"想要完整 XX 笔记,**关注我 + 评论区扣 1**,我私信发你。"——关注是领取门槛,一箭双雕(关注率 + 评论率)。
  - 关注 + 系列预告(留钩子):"XX 系列的下一期明天发,**关注**我,更新第一时间推给你。"——用"怕错过"驱动关注。
  - 关注 + 身份绑定:"考研党 / 宝妈 / 打工人,**点个关注**,这条号专门给你更 XX。"——让观众觉得"这号就是为我开的"。

> 目标 → CTA 映射(Step 6 必须按此对齐,不能只套利益/争议):带货 → 促单 + 利益型;涨粉 → **涨粉/关注型**(可叠加利益型做"关注+扣1"组合);种草 → 收藏型 + 利益型;引流 → 利益型(领资料/私信)。具体话术模板见 `templates/hook-formulas.md` 末尾"CTA 话术速查"。

## 工作流程

按 Step 0 → Step 7 执行,每一步有明确产出。**不要跳步**——跳过 Step 2(钩子候选)直接写全文,是最常见的返工原因。

### Step 0 · 解析输入

从 argument 或对话中提取五个要素,缺哪个问哪个:

| 要素 | 取值 | 示例 |
|------|------|------|
| 主题 | 具体到"一个点",不要"护肤"这种大类 | "敏感肌如何选精华" |
| 形式 | 知识口播 / 剧情 / 种草 / 混剪 | 知识口播 |
| 平台 | 抖音 / 视频号 / 快手 | 抖音 |
| 时长 | 15s / 30s / 45s / 60s / 90s | 45s |
| 目标 | 涨粉 / 带货 / 种草 / 引流 | 种草引流 |

### Step 1 · 锁定形式与平台调性

根据 Step 0 的形式 + 平台,从 `templates/script-formats.md` 取对应结构骨架,再叠加 `templates/platform-tones.md` 的调性清单(用词、BGM、节奏)。输出:一句话形式定义 + 调性标签。

### Step 2 · 生成 3 个黄金 3 秒钩子候选

用 `templates/hook-formulas.md` 的 6 公式,针对主题**各产 1 个**(共 3 个不同公式),给用户选。每个钩子标注:用了哪类公式 + 预估钩子强度(1-10)。用户选定后进入 Step 3。

> 如果用户说"你定就行",默认选强度最高的那个,并说明理由。

### Step 3 · 写完整口播逐字稿

基于选定钩子,按 `templates/script-formats.md` 的结构写口播。强制要求:

- 每句标注停顿(/)和重音(**加粗**)。
- 单句 ≤15 字,超长必拆。
- 总字数 = 时长(s) ÷ 30 × (80~100 字),先算字数预算再写。(例:45s ÷ 30 × 100 = 150 字预算;÷ 30 × 80 = 120 字。即 45s 视频 120-150 字,与 `templates/shot-list-template.md` 的"字数 ≈ 秒数 × 3.3"一致。)
- 按完播率结构(本文件"方法论二")插入转折点,在稿子里用 `[转折]` 标注位置。

### Step 4 · 生成分镜表

用 `templates/shot-list-template.md` 的表格逐镜头拆,**先过"字数→镜头时长分配算法"再填表**:按转折/情绪锚点把口播稿切大段 → 每段按 ≤17 字切镜头 → 时长 = 字数 ÷ 3.3 上取整到 3/5/8 秒 → 镜头秒数相加对账 = 视频时长。每行填:时间轴 / 景别 / 画面内容 / 屏幕字幕 / 口播对应 / BGM 与音效。要求**景别有变化**(全片不能都是中景),关键卖点用特写强化。

填完必须过**逐镜头字数硬自检**(模板里有现成表格):逐镜头列出(秒 / 口播字数 / 字数每秒)三列,**任一镜头 >3.5 字/秒即报红**——拆镜头或删字,改完重算,不许带红交付;全片平均仍守 30 秒 80-100 字。真实语速 2.67-3.33 字/秒,"语速快一点"救不了超载镜头。

### Step 5 · BGM、字幕与拍摄建议

- BGM:按平台调性 + 视频情绪给 2-3 个方向(曲风/参考热点),标注卡点位置。
- 字幕:给字幕风格(字体/颜色/出现方式),关键信息(数字、产品名)要放大或变色。
- 拍摄/素材:真人出镜给机位/光线/背景建议;不出镜给素材来源方向(产品实拍/网图/录屏)。

### Step 6 · CTA 与评论区钩子

按"方法论六",给 2 条结尾 CTA(按目标映射选类型:涨粉必含涨粉/关注型;带货必含促单+利益型;种草必含收藏型)+ 1 条评论区置顶问题(带争议或诱饵)。CTA 要和视频目标对齐(带货→促单,涨粉→关注引导)——目标=涨粉时不得只给利益/争议型,必须有"关注+X"的明确关注引导,话术从 `templates/hook-formulas.md` 的 CTA 速查表取。

### Step 7 · 汇总输出"拍摄版脚本"

把 Step 2-6 的产出整合成一份**可直接交付拍摄**的文档,结构固定为:

```
# 拍摄版脚本 · [主题] · [平台] · [时长]
1. 钩子(已选定):XXX
2. 口播逐字稿(含停顿/重音/转折标注)
3. 分镜表(表格)
4. BGM / 字幕 / 拍摄建议
5. CTA 话术 + 评论区钩子
6. 拍摄 Checklist(口播字数核对 = 总字数预算 + 逐镜头字数每秒 ≤3.5 双过 / 景别多样性 / 钩子强度 / CTA 类型与目标对齐)
```

## 完整示例(以"敏感肌护肤 · 知识口播 · 抖音 · 45s · 种草引流"走一遍)

> 这一节示范方法论如何落地,交付时可作为格式参照。

**Step 0** → 主题=敏感肌选精华;形式=知识口播;平台=抖音;时长=45s;目标=种草引流。
**Step 1** → 形式骨架:钩子→结论→3 点→升华→CTA;调性:快节奏、强钩子、热点 BGM。
**Step 2** → 3 个钩子候选:
1. 冲突型(强度 9):"别再往脸上糊水乳了!敏感肌越护肤越烂脸。"
2. 反常识型(强度 8):"越贵的精华,敏感肌越不能用。"
3. 数字型(强度 7):"敏感肌避开的 5 个成分,第 3 个人人中招。"
用户选定 1。
**Step 3** → 口播逐字稿(以下为节选,完整 121 字稿见 `templates/full-delivery-example.md`,便于照着核对字数预算自检):
> 别再往脸上糊水乳了!/ 敏感肌越护肤,**越烂脸**。/ [转折] 泛红不是过敏,/ 是你**屏障坏了**。/ [转折] 这 3 个成分,/ 才是真救星。/ 第一,**神经酰胺**,修屏障。/ 第二,**积雪草**,镇泛红。/ 第三,**泛醇**,锁水分。/ [情绪锚点] 别让烂脸,/ 毁了你的自信。/ 想要成分避雷表,/ 评论区**扣 1**。
**Step 4** → 分镜表:见 `templates/shot-list-template.md` 的填好的示例表(9 个镜头,按"字数→镜头时长分配算法"切,景别:特写→特写→近景→中景→特写→近景→特写→特写→近景),逐镜头字数硬自检最高 3.3 字/秒,无报红。
**Step 5** → BGM:抖音热点舒缓类卡点曲;字幕:白色大字,成分名黄色加粗放大;拍摄:近景口播对镜 + 产品特写 + 前后对比图。
**Step 6** → CTA:"评论区扣 1,私信你成分避雷表"(利益型);置顶评论:"你觉得神仙水到底适不适合敏感肌?"(争议型)。
**Step 7** → 汇总成拍摄版脚本交付。

**自检通过**:钩子 3 秒内 ✓ / 2 个转折点 ✓ / 中段 3 点干货 ✓ / 情绪锚点"别让烂脸毁自信" ✓ / 字数约 121(45s 预算 120-150)✓ / 逐镜头字数每秒均 ≤3.5(最高 3.3,无报红)✓ / 景别 3 种以上 ✓。

## 边界情况与避坑

这一节是"踩过坑才知道的",直接影响成片能不能过审、能不能推。

**平台违规雷区(会被限流或下架)**
- 抖音:绝对化用语(第一/最好/国家级)、医疗疗效词(根治/特效)、引导站外交易("加微信""主页链接")、低质搬运。
- 视频号:过度营销、诱导分享("转发获赞")、标题党、低俗。
- 快手:虚假宣传功效、刷单话术、违禁品类(医疗器械、处方药)。
- 种草/带货类:未标注"广告"可能违规;产品功效不能超出国妆备案范围。

**常见翻车点**
- **钩子和正文脱节**:钩子说"3 个方法",正文只讲 2 个——观众觉得被骗,差评。
- **口播塞太满**:45 秒塞了 200 字,主播念得喘,观众听不清。守"30 秒 80-100 字"红线。分镜级同样会翻车:单镜头塞出 >3.5 字/秒(如 35 字塞 5 秒),总字数达标也念不完——Step 4 的逐镜头硬自检就是防这个。
- **中段价值塌方**:开头精彩、中间全是废话——完播率断崖。中段必须是干货峰值。
- **景别单一**:全片一个机位一个景别,视觉疲劳。每 10-15 秒换一次景别或画面。
- **CTA 太早**:钩子还没立住就开始"点赞关注",观众反感。CTA 留到最后 5-8 秒。
- **照搬爆款**:爆款的结构可以学,但话术和选题照搬会被判搬运。换场景、换人群重做。

**不适用场景(主动告知用户)**
- 需要实拍高难度运镜/特效的"大片级"视频——本 skill 出脚本不出分镜调度细节。
- 纯剧情/微短剧的复杂多场多角色剧本——本 skill 的剧情形式适合单场景短反转。
- 直播脚本/话术——那是另一套方法论(留人话术 + 逼单话术),不在本 skill 范围。

**跨平台复用注意**
- 同一选题发多平台:**不要直接搬**,要按 `templates/platform-tones.md` 重写钩子和用词。抖音的强冲突钩子发视频号容易被中老年划走。
- 时长也要调:抖音 45s 的内容,视频号可以放到 60-90s(节奏慢、可铺垫)。

## 配置(可选)

读取同目录 `_config.json`(用户不提供就不创建,用默认值)。字段:

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `default_platform` | string | "抖音" | 未指定平台时的默认平台 |

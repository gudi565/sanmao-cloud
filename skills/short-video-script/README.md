# 短视频脚本工厂

> 把一个"主题"变成拍摄现场照着就能拍的短视频脚本。

## 这是什么

这个 skill 解决"短视频脚本写不出、写不好、写完拍不出来"的问题。它把开头 3 秒钩子、完播率结构、口播逐字稿、分镜拆解、CTA 互动这一整套工业化流程封装成 8 步 SOP,产出一份包含钩子候选、口播稿、分镜表、BGM 字幕建议的**拍摄版脚本**。不是靠灵感写文案,而是按结构稳定产出能交付的成稿。

## 30 秒上手

1. **安装**:把整个 `short-video-script/` 文件夹放到 `~/.claude/skills/` 下(或项目级 `.claude/skills/`)
2. **调用**:在 Claude Code 里输入 `/short-video-script <主题> [形式]`
3. **拿结果**:按 Step 0→7 分步流程产出拍摄版脚本,复制即用

示例:

```
/short-video-script 敏感肌平价水乳推荐 知识口播
```

也可以只给主题,skill 会问你补齐平台、时长、目标。

## 它能帮你做什么

- **生成 3 个黄金 3 秒钩子候选**,覆盖冲突/反常识/数字等 6 类公式,带强度评分,便于 A/B
- **写口播逐字稿**,自动控制单句字数、标注停顿和重音、按时长算字数预算
- **拆分镜表**,逐镜头给时间轴、景别、画面、字幕、口播、BGM,景别变化防视觉疲劳
- **适配抖音/视频号/快手三大平台**的节奏、钩子风格和人群调性
- **覆盖四种视频形式**:知识口播、剧情演绎、好物种草、口播+素材混剪
- **给 CTA 和评论区钩子**,拉升点赞、评论、收藏、关注互动率

## 适合谁

- **短视频创作者/自媒体**:自己起号,需要批量稳定出脚本而不是靠灵感
- **电商带货主播/种草号**:要把一个产品快速改成可拍的带货脚本
- **知识付费博主/口播号**:把知识沉淀成完播率高的口播逐字稿
- **MCN 脚本岗/本地商家**:需要可交付、可复用的脚本 SOP,减少返工

## 包含什么

- `SKILL.md`(225 行)— 主文件:核心方法论(钩子/完播结构/口播/四种形式/平台调性/CTA)+ 8 步工作流 + 平台违规避坑 + 完整示例
- `templates/` — 5 个可直接套用的模板:
  - `hook-formulas.md` — 6 类钩子公式 + 逐主题套用示范 + 自检清单
  - `script-formats.md` — 四种视频形式的结构骨架
  - `platform-tones.md` — 抖音/视频号/快手调性差异对照表
  - `shot-list-template.md` — 6 列标准分镜表(含填好的示例)+ 景别速查
  - `full-delivery-example.md` — 一份完整交付脚本,可作格式参照
- `LISTING.md` 是市场上架文案,日常使用可忽略

## 看看效果

以"敏感肌护肤 · 知识口播 · 抖音 · 45s"为例,Step 2 产出的钩子候选:

```
1. 冲突型(强度 9):"别再往脸上糊水乳了!敏感肌越护肤越烂脸。"
2. 反常识型(强度 8):"越贵的精华,敏感肌越不能用。"
3. 数字型(强度 7):"敏感肌避开的 5 个成分,第 3 个人人中招。"
```

Step 3 的口播逐字稿节选(带停顿/重音/转折标注):

```
别再往脸上糊水乳了!/ 敏感肌越护肤,**越烂脸**。
/ [转折] 泛红不是过敏,/ 是你**屏障坏了**。
/ [转折] 这 3 个成分,/ 才是真救星。
```

## 常见问题

- **要不要联网?** 建议联网。写脚本前用 WebSearch 校准选题热点、平台用词、产品卖点会更准;不联网也能出稿,但热点类、带货类选题建议开网。
- **能不能自定义?** 可以。在 skill 同目录放一个 `_config.json`,可设默认平台、时长、形式、钩子数量、脚本语气等(见下节)。
- **支持什么平台/语言?** 抖音、视频号、快手;中文。

## 配置(可选)

无需配置即可开箱即用。如需调整默认行为,在同目录新建 `_config.json`,常用字段:

| 字段 | 默认 | 说明 |
|------|------|------|
| `default_platform` | `"抖音"` | 未指定平台时的默认值 |
| `default_duration` | `45` | 默认时长(秒) |
| `default_format` | `"知识口播"` | 默认视频形式 |
| `hook_candidates` | `3` | Step 2 生成的钩子候选数 |
| `tone` | `"专业实战"` | 脚本语气:专业实战 / 轻松活泼 / 接地气 |
| `target_audience` | `""` | 目标人群描述,影响用词和钩子选择 |

调用时带参数(如 `敏感肌护肤 知识口播`)会覆盖配置默认值。

# 四种视频形式结构模板

先定形式,再填结构。四种形式各有独立的完播骨架,不能混用。下表是选择参考,后面是每种形式的逐段拆解。

## 形式选择速查

| 你的目标 | 推荐形式 | 为什么 |
|----------|----------|--------|
| 涨粉 / 知识付费 / 个人 IP | 知识口播 | 人设强、信息密度高、易复用 |
| 吃剧情流量 / 情感共鸣 | 剧情演绎 | 完播高、易爆,但脚本门槛高 |
| 带货 / 种草 / 引流下单 | 好物种草 | 痛点-产品-效果闭环,促单直接 |
| 不出镜 / 快节奏 / 信息流 | 口播+混剪 | 量产快、成本低、适合工具号 |

---

## 形式一 · 知识口播

**结构骨架**:钩子 → 结论先行 → 分点论证(3 点) → 总结升华 → CTA

| 段落 | 时长占比 | 内容 | 情绪点 |
|------|----------|------|--------|
| 钩子 | 0-3s | 抛问题/反常识 | 好奇 |
| 结论先行 | 3-8s | 先给答案,再讲为什么 | 认同 |
| 分点论证 | 8-70% | 3 个论据/方法,每点一个画面 | 惊喜/信任 |
| 总结升华 | 70-90% | 一句话拔高、价值观 | 信任 |
| CTA | 90-100% | 关注/收藏/评论 | 行动 |

**口播节奏示例(45s)**:
> [钩子] 你知道 XX 吗?/ [结论] 其实是 YY。/ [转折] 这 3 点,记牢。/ 第一,…… / 第二,…… / 第三,…… / [升华] 别让 XX 毁了你。/ [CTA] 收藏这条,下次照着做。

**适用**:科普、职场、育儿、财商、健康知识、方法论类账号。

---

## 形式二 · 剧情演绎

**结构骨架**:场景设定 → 冲突爆发 → 反转/解决 → 价值观升华

| 段落 | 时长占比 | 内容 | 情绪点 |
|------|----------|------|--------|
| 场景设定 | 0-15% | 交代人物/场景,埋钩子 | 代入 |
| 冲突爆发 | 15-40% | 矛盾出现,激发情绪 | 紧张/愤怒 |
| 反转/解决 | 40-80% | 意想不到的转折 | 惊喜 |
| 价值观升华 | 80-100% | 点题、共鸣 | 信任/行动 |

**脚本要素清单**:
- 角色:主角 + 对立面(不超过 3 个有台词角色)。
- 场景:尽量单场景,降低拍摄成本。
- 反转:必须有 1 个"意料之外、情理之中"的转折,这是剧情视频的灵魂。
- 台词:口语、短,忌书面;每句带情绪。

**适用**:情感剧情、家庭矛盾、职场反转、品牌故事、社会议题。

> 翻车点:反转不成立 = 剧情视频失败;没有价值观升华 = 流量来了但不涨粉。

## 形式三 · 好物种草

**结构骨架**:共鸣痛点 → 抛出产品 → 拆解卖点(场景化) → 效果展示 → 促单 CTA

| 段落 | 时长占比 | 内容 | 情绪点 |
|------|----------|------|--------|
| 共鸣痛点 | 0-15% | "你是不是也……" | 共鸣 |
| 抛出产品 | 15-25% | 产品出场,制造期待 | 好奇 |
| 拆解卖点 | 25-65% | 2-3 个卖点,每个配使用场景 | 认同/惊喜 |
| 效果展示 | 65-85% | 前后对比/真实体验 | 信任 |
| 促单 CTA | 85-100% | 下单引导/优惠/紧迫感 | 行动 |

**卖点拆解规则**:
- 每个卖点必须配**一个具体场景**,不能只说"好用"。
- 卖点排序:**解决最大痛点的那个放第一个**。
- 效果展示尽量**可视化**(前后对比、实测、数据)。

**口播节奏示例(45s)**:
> [痛点] 换季脸又红了?/ [产品] 这瓶精华,我用了 3 个月。/ [卖点1] 神经酰胺,修屏障。/ [卖点2] 无酒精,敏感肌放心。/ [卖点3] 28 天,泛红真的淡了。/ [效果] 看前后对比。/ [CTA] 链接在下方,趁活动囤。

**适用**:美妆、护肤、数码、家居、食品、本地商家带货。

## 形式四 · 口播 + 素材混剪

**结构骨架**:口播为骨架(画外音) + 素材画面快切填视觉

| 段落 | 时长占比 | 内容 |
|------|----------|------|
| 口播钩子 | 0-3s | 画外音抛钩子 + 强视觉素材 |
| 价值铺垫 | 3-15% | 口播讲背景 + 素材支撑 |
| 信息快切 | 15-85% | 口播密集输出,画面 2-3 秒一切 |
| CTA | 85-100% | 口播引导 + 产品/账号画面 |

**关键技巧**:
- 口播是信息主体,画面只负责"不枯燥"。
- 画面切换节奏要**快**(2-3 秒一换),但口播语速不能乱(守 30 秒 80-100 字)。
- 素材来源:产品实拍、网图、录屏、数据图表、相关视频片段(注意版权)。
- 字幕是重点——画面快切时,观众靠字幕抓信息。

**适用**:不出镜的工具号、资讯号、盘点号、知识快剪号;量产首选。

> 优势:成本低、日更可行、适合矩阵号。劣势:人设弱,难沉淀粉丝信任,带货转化弱于出镜口播。

---

## 通用:完播率自检(所有形式通用)

- [ ] 钩子是否在前 3 秒?
- [ ] 是否每 15-20 秒有一个转折/新钩子?
- [ ] 中段(40-70%)是否价值密度最高?
- [ ] CTA 前是否有情绪锚点?
- [ ] 口播总字数是否匹配时长(30 秒 80-100 字)?
- [ ] 景别/画面是否有变化?

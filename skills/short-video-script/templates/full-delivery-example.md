### 4. BGM / 字幕 / 拍摄建议

**BGM**:抖音热点舒缓类卡点曲(参考"治愈系护肤 vlog"类目),16s、24s、29s 三个成分卡点处加"叮""嗖""叮"三声轻音效强化记忆。情绪在 29s 后从平缓转上扬。

**字幕**:
- 字体:思源黑体 Bold,白色,描黑边。
- 关键词变色放大:**屏障坏了**(红色)、**神经酰胺 / 积雪草 / 泛醇**(黄色加粗,放大 1.3 倍)、**扣 1**(橙色高亮)。
- 出字方式:钩子句"砸"出来(0.1s 弹入),正文句"滑"入,数字"跳数"动效。

**拍摄/素材**:
- 真人出镜:近景口播对镜(环形灯正面补光,背景纯色或浅色家居,避免杂乱)。
- 素材:产品成分瓶特写(手机 + 微距镜头即可)、前后对比图(可网图授权或自拍)、28 天时间轴用剪辑软件动画。
- 服装:素色、干净,避免与字幕颜色冲突。

### 5. CTA 话术 + 评论区钩子

**结尾 CTA(二选一,让用户定)**:
- 利益型(默认):"想要完整成分避雷表,评论区扣 1,我私信你。"——拉升评论 + 私域引流。
- 争议型:"你觉得神仙水到底适不适合敏感肌?评论区聊聊。"——制造对立拉升评论率。

> 本例目标 = 种草引流,按 `hook-formulas.md` CTA 速查的"目标→CTA 组合规则"出利益型 + 争议型;若目标改为涨粉,必出涨粉/关注型(如"想要完整避雷表,关注我+评论区扣 1,我私信发你"),不得只给利益/争议型。

**评论区置顶钩子**(发布后立刻自己置顶):
> "敏感肌最该避开的不是贵的产品,是这 3 个成分 👉 扣 1 领完整表。你用过最踩雷的敏感肌产品是啥?"

## 使用说明

1. 第一次交付:直接照这份的结构 1:1 填你自己的主题内容。
2. 结构固定为 6 个区块,顺序不要调——拍摄者按这个顺序拿信息。
3. Checklist 是交付前的最后一道关,每条都要过。口播字数核对(总字数预算 + 逐镜头秒速双过)和景别多样性是最容易被忽略的两条。
4. 同一选题发多平台时,这份样板只换"钩子 + BGM + 字幕风格"三块,结构骨架可复用。

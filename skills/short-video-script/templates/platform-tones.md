# 平台调性差异与适配清单

**同一条脚本换个平台,可能完全不推。** 下表是三大平台的核心差异,Step 1 锁定调性时逐项对照,跨平台复用时据此改写。

## 三平台核心对比

| 维度 | 抖音 | 视频号 | 快手 |
|------|------|--------|------|
| 节奏 | 快,前 3 秒定生死 | 中慢,可铺垫 5-8 秒 | 中,真实为先 |
| 主力人群 | 18-35,爱新鲜、爱爽感 | 35+,中老年多,熟人圈层 | 下沉市场,看重实惠 |
| 钩子风格 | 强冲突、反常识、热点梗 | 温情、价值观、故事感 | 接地气、老铁话术 |
| 用词 | 网感词、流行梗可用 | 大白话、忌生僻网络词 | 方言/口语、"老铁""家人们" |
| BGM | 热点卡点、节奏强 | 舒缓、抒情、经典老歌 | 乡土流行、接地气 |
| 信任来源 | 人设、爽感、专业感 | 真实、熟人推荐、价值观共鸣 | 真实、人味、像邻居 |
| 时长偏好 | 15-60s,短平快 | 45-90s,可讲故事 | 30-90s,真实记录 |
| CTA | "关注看更多""扣 1" | "转发给家人""点赞收藏" | "老铁双击""关注不迷路" |
| 推荐逻辑 | 完播率 + 互动率 | 社交推荐(朋友点赞)为主 | 关注页 + 算法 |

## 抖音适配清单

- [ ] 钩子是否在 3 秒内抛出?(抖音 3 秒划走率极高)
- [ ] 是否用了近期热点 BGM 或卡点?(流量加成)
- [ ] 节奏是否紧凑?(每 15 秒一个转折)
- [ ] 字幕是否够大、够醒眼?(竖屏手机观看)
- [ ] 结尾 CTA 是否引导互动?(评论/收藏拉升推荐)
- [ ] 避免站外引流话术("加微信"会被限流)

## 视频号适配清单

- [ ] 钩子是否偏温情/价值观?(强冲突容易被中老年划走)
- [ ] 用词是否通俗、无生僻网络梗?
- [ ] 是否有"转发给家人/朋友"的动机?(社交推荐是核心)
- [ ] BGM 是否舒缓、不刺耳?
- [ ] 信任感是否够?(真实案例、亲身经历优于硬广)
- [ ] 避免过度营销、诱导分享话术

## 快手适配清单

- [ ] 是否用了"老铁""家人们"等亲切称呼?
- [ ] 画面是否真实、不过度精致?(太像广告反而掉粉)
- [ ] 是否凸显性价比/实惠?(下沉人群敏感)
- [ ] 是否有人味/故事感?(真人真实 > 包装感)
- [ ] CTA 是否用"双击""关注老铁"?

## 跨平台复用规则

同一选题发多平台时:
1. **选题可以共用**,钩子要按平台重写(抖音强冲突 → 视频号温情 → 快手接地气)。
2. **时长调**:抖音 45s → 视频号 60-90s → 快手 45-60s。
3. **用词调**:网感词在抖音 OK,视频号换大白话,快手换口语方言。
4. **BGM 必换**:三平台热门曲库和审美不同。
5. **CTA 调**:抖音"扣 1" → 视频号"转发给家人" → 快手"双击"。

> 经验:先做抖音版(钩子最强、结构最严),再向另外两平台降维改编,效率最高。

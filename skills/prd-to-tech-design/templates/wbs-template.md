# WBS 任务拆解表模板

> 拆解原则:任务名用动宾结构;粒度 0.5–2 人天;标注前置依赖与可并行性;合计后加 30% 联调 buffer。

## 一、任务清单(按模块分组)

### 模块 A:[模块名]

| 任务ID | 任务名(动宾结构) | 负责人 | 估时(人天) | 前置依赖 | 可并行? | 产出物 |
|--------|------------------|--------|------------|---------|--------|--------|
| A-01 | 创建 [模块A] 数据表与索引 | | 0.5 | - | 是 | DDL 脚本 |
| A-02 | 实现 [模块A] Model 与 DAO | | 1 | A-01 | 是 | 代码 |
| A-03 | 实现 [创建X] 接口(含幂等) | | 1.5 | A-02 | 否 | 接口+单测 |
| A-04 | 实现 [查询X列表] 接口(含分页) | | 1 | A-02 | 是 | 接口+单测 |
| A-05 | 实现 [更新X] 接口(含乐观锁) | | 1 | A-02 | 是 | 接口+单测 |
| A-06 | 编写接口文档与 Mock | | 0.5 | A-03~A-05 | 否 | 文档 |

## 二、关键路径(决定整体周期)

最长依赖链:
A-01 → A-02 → A-03 → 联调 → 测试 → 上线

```
[A-01 0.5d] → [A-02 1d] → [A-03 1.5d] → [联调] → [测试]
                  ↘ [A-04 1d] ↗
                  ↘ [A-05 1d]↗
```

## 三、并行机会

| 可并行任务组 | 说明 |
|-------------|------|
| A-04 与 A-05 | 都依赖 A-02,互不冲突,可双人并行 |
| 模块A前端 与 模块A后端 | 后端先出 Mock,前端并行开发 |

## 四、汇总与排期

| 阶段 | 工时(人天) | 计算说明 |
|------|-----------|---------|
| 开发合计 | Σ 各模块 | |
| 联调 | 开发 × 30% | 标准缓冲 |
| 测试 | 视测试团队而定 | |
| 灰度+上线 | 1–2 天 | 含回滚演练 |
| **总计** | | |

## 五、风险预留

| 风险点 | 预留 buffer |
|--------|------------|
| 依赖第三方联调 | +2 天 |
| 涉及数据迁移 | +1 天 |
| 团队对新技术栈不熟 | ×1.2 系数 |

## 六、估时自检

- [ ] 每个任务是否都拆到 ≤ 2 人天?(>2 天的继续拆)
- [ ] 是否标注了前置依赖?(漏标会导致排期撞车)
- [ ] 是否预留了联调与 bugfix buffer?
- [ ] 关键路径是否找出来了?(它决定上线日期)
- [ ] 并行任务是否真的无冲突?(共享代码、共享环境不算并行)

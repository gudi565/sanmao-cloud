# 风险识别 Checklist

> 套用方法:每类至少过一遍,逐条回答"本次是否涉及"。涉及则写对策,不涉及则标注"已评估,无"。评审时按此表对照。

## 一、性能风险

| 风险点 | 是否涉及 | 对策 |
|--------|---------|------|
| 慢查询(SQL 扫全表) | [ ] | 加索引;`EXPLAIN` 验证命中;禁止 `SELECT *` |
| N+1 查询(列表循环查详情) | [ ] | 用 JOIN 或批量预取(`WHERE id IN (...)`) |
| 缓存击穿(热点 key 失效瞬间压 DB) | [ ] | 互斥锁重建 / 永不过期+异步刷新 |
| 缓存穿透(查不存在的 key) | [ ] | 空值缓存 / 布隆过滤器 |
| 缓存雪崩(大量 key 同一时刻 TTL 集中失效) | [ ] | TTL 加随机抖动 ±10%;多级缓存;热点 key 永不过期+异步刷新 |
| 大表深分页(`LIMIT 10000,20`) | [ ] | 改游标分页(基于 id / 时间) |
| 大对象传输(列表返回字段过多) | [ ] | 列表与详情接口分离;字段裁剪 |
| 批量操作无分批(一次拉全表) | [ ] | 强制分页/分批,上限封顶 |

## 二、安全风险

| 风险点 | 是否涉及 | 对策 |
|--------|---------|------|
| 水平越权(A 能看 B 的数据) | [ ] | 查询/更新强制带当前用户 id 过滤 |
| 垂直越权(普通用户能调管理接口) | [ ] | 接口级权限校验,不信任前端隐藏按钮 |
| SQL 注入 | [ ] | 全部用参数化查询/ORM,禁止字符串拼接 |
| XSS(用户输入回显页面) | [ ] | 输出转义;富文本白名单过滤 |
| 敏感数据泄露(手机号/身份证明文返回) | [ ] | 脱敏展示(138****1234);加密存储 |
| 日志泄露(密码/token 打进日志) | [ ] | 敏感字段日志脱敏中间件 |
| 接口防刷(无限刷短信/登录爆破) | [ ] | 限流(IP/账号维度)+ 滑动窗口 |

## 三、兼容风险

| 风险点 | 是否涉及 | 对策 |
|--------|---------|------|
| 老版本客户端不兼容 | [ ] | 接口版本化(`/v1/` `/v2/`);字段只增不减 |
| 数据库 DDL 影响线上 | [ ] | 大表改用 pt-osc/gh-ost;先加字段双写 |
| 字段重命名/删除 | [ ] | 不删,先标记废弃;观察一个周期再清理 |
| 老数据缺失新字段 | [ ] | DDL 给默认值;启动时回填 |
| 第三方接口变更 | [ ] | 契约测试;版本钉死 |

## 四、依赖风险

| 风险点 | 是否涉及 | 对策 |
|--------|---------|------|
| 第三方服务不可用 | [ ] | 超时设置(3s)+ 重试(指数退避)+ 降级(默认值/缓存) |
| 第三方限流 | [ ] | 本地限流;请求合并;异步队列削峰 |
| 依赖组件单点(Redis/MySQL/MQ) | [ ] | 主从/集群;故障切换演练 |
| 下游接口变慢拖垮自己 | [ ] | 线程池隔离 / 信号量隔离 / 熔断 |
| 循环依赖(服务间互相调用) | [ ] | 拆公共下沉服务;异步解耦 |

## 五、容量风险

| 风险点 | 是否涉及 | 对策 |
|--------|---------|------|
| 单表数据量过大(经验值 2000–5000 万行,视行宽与索引数而定) | [ ] | 达阈值即评估分库分表 / 归档冷数据 / 按时间切表;行宽越大触发越早 |
| 磁盘/带宽不足 | [ ] | 容量预估;监控告警阈值 |
| 缓存内存不足 | [ ] | 设置 TTL + 淘汰策略;容量监控 |
| 日志/消息积压 | [ ] | 消费速率监控;死信队列;告警 |

## 六、一致性风险

| 风险点 | 是否涉及 | 对策 |
|--------|---------|------|
| 跨服务/跨库写数据不一致 | [ ] | 选 saga / TCC / 本地消息表 / 对账,明确选哪种 |
| 消息重复消费 | [ ] | 消费端幂等(业务唯一键去重) |
| 缓存与 DB 不一致 | [ ] | 明确策略:先更 DB 再删缓存 / 延迟双删 |
| 状态机非法跃迁 | [ ] | 状态流转表 + 校验,禁止直接更新 status |
| 并发重复创建 | [ ] | 唯一约束 + 幂等键 |
| 分布式锁未释放 | [ ] | 锁加 TTL + 看门狗续期;finally 释放 |

## 评审重点(风险章节必答)

- [ ] 涉钱/库存的写操作,幂等键是什么?
- [ ] 跨服务一致性用哪种方案?为什么选它?
- [ ] 第三方挂了,降级返回什么?用户体验是什么?
- [ ] 上线后某个 DDL 慢,是否阻塞写?有没有在线 DDL 方案?

# 绘画流派速查参考

> **用途**：当画者提出一个主题、情绪或方向时，从这份清单中快速找到视觉语言最契合的流派作为"参考方向"。每个条目都面向创作者——不写百科词条，只写"它长什么样、什么主题用它最对、当代画者能从它偷走什么"。
>
> **使用方式**：先读"一句话 DNA"判断是否契合，再看"视觉语言"和"可借鉴点"决定如何下手。代表画家列出的姓名都可单独作为下一步检索的关键词。
>
> **结构说明**：西方脉络按时代排列；东方脉络按媒材/传统排列；其他传统单列。共 38 个流派。文末附"如何选派别"决策提示。

---

## 第一部分：西方脉络

### 一、古典与学院体系

### 文艺复兴（Renaissance）
- **年代/地区**：15—16 世纪，以意大利为中心，辐射北欧与西班牙
- **一句话 DNA**：以透视法、解剖学与明暗塑造重建可信的人间空间，神被画成有血肉的人
- **视觉语言**：明度整体偏中高调、过渡平稳 / 色彩以赭石、土红、群青、维罗纳绿为主的有限调色板 / 笔触平整细腻、追求不见痕 / 构图金字塔或对称三角、单点透视
- **代表画家**：达·芬奇（晕涂法 sfumato 的发明者）、米开朗基罗（人体雕塑感的极致）、拉斐尔（构图平衡的范本）、扬·凡·艾克（北方油画的发明者）、丢勒（北方版画与自画像先驱）
- **适合表达**：宗教/神话题材中的庄严人体、可信的空间、理性的秩序感、永恒感
- **可借鉴点**：达·芬奇的"晕涂法"——让轮廓消失在阴影里，明暗边界柔化到看不见笔触；肖像或人体要"沉得住气"时的不二法门

### 巴洛克（Baroque）
- **年代/地区**：17 世纪，意大利发源，西班牙/荷兰/法兰德斯并盛
- **一句话 DNA**：以极端明暗对比与戏剧性动势把宗教与世俗推向剧场化的情绪高峰
- **视觉语言**：明度对比极端（暗调为主）/ 色彩深褐、酒红、金、骨白 / 笔触奔放可见、厚薄变化大 / 构图对角线、动势瞬间、戏剧性高潮
- **代表画家**：卡拉瓦乔（明暗剧场的发明者）、伦勃朗（光的诗人，心理深度）、委拉斯凯兹（宫廷写实的松弛笔触）、鲁本斯（肉感与动势的巴洛克）、维米尔（日常生活里的静光大师）
- **适合表达**：戏剧性瞬间、强烈情绪、宗教狂喜、市井日常里的庄严、心理深度
- **可借鉴点**：卡拉瓦乔"明暗对比法"（chiaroscuro）——主体从深色背景里浮出，一束侧光打亮要点；任何肖像、静物、室内一旦"打光"就立刻立住

### 洛可可（Rococo）
- **年代/地区**：18 世纪，法国
- **一句话 DNA**：巴洛克的甜腻私生子——粉彩色、不对称贝壳曲线、贵族调情场景
- **视觉语言**：明度整体偏高调、明亮 / 色彩粉红、薄荷绿、奶油白、淡紫、金 / 笔触轻盈细碎 / 构图不对称的 S 曲线、对角线、华丽装饰
- **代表画家**：华托（"雅宴画" fête galante 的发明者）、布歇（宫廷甜美的极致）、弗拉戈纳尔（《秋千》的轻佻大师）、夏尔丹（静物里的安静，反洛可可的清醒）
- **适合表达**：轻盈、感官、嬉戏、私密、女性化、春日与情欲的甜美
- **可借鉴点**：洛可可"糖罐调色板"——粉红 + 薄荷绿 + 奶油白的并置，画少女、甜点、春光、室内小景时的"高级糖感"配方；切忌用得过满

### 新古典主义（Neoclassicism）
- **年代/地区**：18 世纪末—19 世纪初，法国
- **一句话 DNA**：以古希腊罗马的肃穆造型回敬洛可可的轻佻，线条优先于色彩
- **视觉语言**：明度平均、中调平稳 / 色彩冷峻低饱和、大理石白、深红与墨黑 / 笔触不见痕、表面光滑如瓷 / 构图浮雕式平面、轮廓硬朗、对称
- **代表画家**：大卫（革命时期的道德画家）、安格尔（素描派的极致、椭圆背脊的发明者）、卡诺瓦（雕塑，可作造型参考）
- **适合表达**：崇高、英雄主义、悲剧、道德克制、纪念碑感
- **可借鉴点**：安格尔"轮廓优先"工作法——先用极精准的线描锁形再淡彩填充；画端庄肖像、人体、古典场景时的纪律感来源

### 二、19 世纪的反叛与突破

### 浪漫主义（Romanticism）
- **年代/地区**：18 世纪末—19 世纪中，欧洲
- **一句话 DNA**：以激情、自然、想象与个人反抗理性——画风暴、屠杀、废墟与远方的英雄
- **视觉语言**：明度对比强烈、暗部厚重 / 色彩饱和暖红、深蓝、土褐、暴风雨灰 / 笔触可见、动势感强 / 构图不安定、对角线、近景裁切
- **代表画家**：德拉克洛瓦（色彩激情派的旗手）、戈雅（黑暗人心的描摹者）、弗里德里希（风景中的孤独形而上）、透纳（光与大气溶解一切）、热里科（《梅杜莎之筏》）
- **适合表达**：激情、恐惧、崇高、孤独、风暴、暴力、远方、形而上的忧伤
- **可借鉴点**：弗里德里希"背影面对辽阔"的构图——人物背对观众望向远方风景，制造代入式的崇高感；适合当代"孤独""远方""内心"题材

### 现实主义（Realism）
- **年代/地区**：19 世纪中叶，法国
- **一句话 DNA**：只画眼睛能看到的当代日常——劳工、农民、小市民，拒绝理想化
- **视觉语言**：明度中性、灰调 / 色彩土褐、橄榄绿、低饱和大地色 / 笔触朴实平稳 / 构图平凡瞬间、不刻意美化的视角
- **代表画家**：库尔贝（"我画我看见的"宣言者）、米勒（农民史诗的发明者）、柯罗（银灰风景）、杜米埃（社会讽刺的素描大师）
- **适合表达**：平凡生活的尊严、阶级、土地、劳作、质朴的人物
- **可借鉴点**：库尔贝"写实 palette"——把所有颜色降到土系（土黄、土红、橄榄、生褐、煤黑），让画面立刻获得"现场感"而不甜；处理当代市井/生活流题材时的降甜神器

### 哈德逊河派（Hudson River School）
- **年代/地区**：19 世纪中叶，美国
- **一句话 DNA**：把美国荒野画成神圣的应许之地，光就是上帝
- **视觉语言**：明度高调、辉煌 / 色彩金橙日出、青翠远景、霞紫云层 / 笔触细腻写实 / 构图广角全景、近—中—远三段清晰
- **代表画家**：托马斯·科尔（奠基者）、弗雷德里克·丘奇（全景的极致）、阿尔伯特·比尔斯塔特（西部的宏伟）、桑福德·吉福德（光雾冥想派）
- **适合表达**：壮丽山河、神圣光、人对自然的渺小、史诗风景、家园神话
- **可借鉴点**：丘奇"光轴构图"——让一束光从云缝或山隙直射焦点区域，整张画立刻有神圣感；处理风景时把光当主角而不是装饰

### 印象派（Impressionism）
- **年代/地区**：1860s—1880s，法国
- **一句话 DNA**：走出画室画外光下的瞬间，光本身成为主角
- **视觉语言**：明度偏高调、避免纯黑 / 色彩高饱和原色并置、补色并置 / 笔触破碎可见的彩色小笔触 / 构图非中心、受浮世绘影响的裁切感
- **代表画家**：莫奈（系列外光大师，干草堆/睡莲）、雷诺阿（光中的肉感人物）、德加（芭蕾舞者的奇视角）、毕沙罗（印象派的导师）、卡萨特（母与子）
- **适合表达**：瞬间、空气、阳光、休闲、现代生活的轻盈、户外的"那束光"
- **可借鉴点**：莫奈"补色并置"——阴影里画互补色（黄物体的紫阴影），亮部画相邻色，远看自动调和，比直接调灰鲜活得多；想要"会呼吸的光"必练

### 后印象派（Post-Impressionism）
- **年代/地区**：1880s—1900s，法国
- **一句话 DNA**：印象派之后的四条分叉——结构（塞尚）、情感（梵高）、象征（高更）、科学（修拉）
- **视觉语言**：四派各异——塞尚的几何色块 / 梵高的螺旋笔触 / 高更的平涂象征 / 修拉的点彩 / 色彩饱和主观 / 笔触强烈表达性 / 构图主观重构
- **代表画家**：塞尚（"用圆柱体、球体、圆锥体处理自然"）、梵高（情感笔触的极端）、高更（原始象征主义）、修拉（科学点彩）、塞律西埃（纳比派前奏）
- **适合表达**：主观情感、形式探索、内在节奏、原始与神秘、画的"造"而非"摹"
- **可借鉴点**：塞尚"色块建构法"——把对象简化为几何色块的层叠，每一笔同时承担形与色；当代绘画里"建构感"的源头，从立体主义到弗洛伊德都受此影响

### 象征主义（Symbolism）
- **年代/地区**：1880s—1900s，欧洲
- **一句话 DNA**：用梦境的视觉密码传递无法言说的内心——神话、死亡、欲望、命运
- **视觉语言**：明度偏暗中调 / 色彩深沉、神秘紫绿黑金 / 笔触柔和或平涂 / 构图对称仪式感、平面化
- **代表画家**：古斯塔夫·莫罗（神话迷宫的造梦者）、皮维·德·夏凡纳（沉静壁画）、勃克林（《死之岛》）、克里姆特（金饰象征，跨维也纳分离派）、蒙克（焦虑的先驱，跨表现主义）
- **适合表达**：梦境、命运、死亡、性、神秘、心理隐秘、形而上的忧郁
- **可借鉴点**：克里姆特"装饰性象征"——用图案、金箔、纹样把私人欲望符号化为平面装饰；适合女性主题、情欲、神话再译

### 纳比派（Les Nabis）
- **年代/地区**：1888—1900，法国
- **一句话 DNA**：把高更的综合主义做成"平面装饰的灵性画学"——画是色块的安排，不是窗户
- **视觉语言**：明度简化为二三层 / 色彩主观平涂、轮廓圈色块 / 笔触不见痕、平涂 / 构图 Japanisme 装饰性、画面是平面而非纵深
- **代表画家**：博纳尔（光与图案的家庭神话）、维亚尔（室内图案的沉浸者）、塞律西埃（《护身符》的发起者）、莫里斯·丹尼斯（理论家）
- **适合表达**：室内亲密、家庭日常的神秘化、女性、图案与织物的迷醉、中产阶级室内的"潮湿"
- **可借鉴点**：博纳尔"图案淹没主体"——让墙纸、桌布、衣物的图案爬过人物轮廓，主体被装饰溶解；处理"室内感""亲密关系"时的高阶手法

### 三、20 世纪现代主义大爆发

### 表现主义（Expressionism）
- **年代/地区**：1905—1925，德国为主（"桥社"与"青骑士"两脉）
- **一句话 DNA**：把内心焦虑直接外化成扭曲的形与刺眼的色——真实高于美
- **视觉语言**：明度对比强烈、节奏跳跃 / 色彩主观极端、刺目互补、原色直接用 / 笔触粗暴、刀痕、划痕 / 构图挤压、变形、不安定
- **代表画家**：蒙克（先驱，焦虑的视觉化）、基希纳（街头紧张感的发明者）、康定斯基（走向抽象的表现主义者）、诺尔德（宗教色彩的狂热）、珂勒惠支（黑白的人道悲悯）
- **适合表达**：焦虑、恐惧、社会批判、内心冲突、性、死亡、城市疏离
- **可借鉴点**：基希纳"街头骨架化"——把人物拉长、骨感化、配刺眼色并置；当代画都市疏离、人群题材的视觉配方

### 野兽派（Fauvism）
- **年代/地区**：1905—1907，法国（极短暂但影响深远）
- **一句话 DNA**：颜色从描述中解放——直接用颜料管挤出来的纯色画情感
- **视觉语言**：明度高对比 / 色彩纯度爆炸、绿影子红脸、纯色直接并置 / 笔触狂放直接 / 构图平面化、装饰性
- **代表画家**：马蒂斯（领袖，最简的极致）、德兰（伦敦风景的纯色爆炸）、弗拉曼克（最野的野兽）、杜菲（水彩感的轻快野兽）、鲁奥（厚重黑轮廓的悲悯）
- **适合表达**：快乐、感官、生命力、纯色本身的力量、室内欢愉
- **可借鉴点**：马蒂斯"减法三原则"——色少、形简、留白多；用三四个大色块就能撑起一张画，是处理"复杂主题想简化"时的范本

### 立体主义（Cubism）
- **年代/地区**：1907—1925，法国
- **一句话 DNA**：把三维物体拆成多个视角的碎片，同时并置在二维平面上
- **视觉语言**：明度中性、低饱和棕灰（分析期）/ 色彩拼贴纸与原色（综合期）/ 笔触平整、几何切面 / 构图多层平面叠压、轮廓错位
- **代表画家**：毕加索（无穷的形式发明者）、布拉克（更内省的合伙人）、莱热（机械感的圆柱人体）、格里斯（最严整的古典立体主义）
- **适合表达**：多重视角、物体的几何本质、平面与空间的辩证、分析与解构
- **可借鉴点**：毕加索"轮廓线斗争"——同一条轮廓既属于这个物体也属于那个物体，形状互相争夺边界；处理"形与形互嵌""多义轮廓"的当代构图

### 未来主义（Futurism）
- **年代/地区**：1909—1916，意大利
- **一句话 DNA**：礼赞速度、机器、暴力与战争，把运动和时间拍进一张静态画
- **视觉语言**：明度高对比 / 色彩补色振动、原色 / 笔触重复动势线、模糊叠影 / 构图对角线、放射状、动势延续到画面外
- **代表画家**：巴拉（《拴着皮带的狗》的动态）、塞韦里尼（夜总会的光之舞）、波丘尼（《城市的兴起》）、卡洛·卡拉
- **适合表达**：速度、机械、能量、城市喧嚣、运动、技术崇拜
- **可借鉴点**：巴拉"重复轮廓法"——把运动物体的轮廓重复画多次形成叠影，像长曝光；适合当代"运动感""速度感"主题

### 超现实主义（Surrealism）
- **年代/地区**：1924 年起，发于法国，跨国
- **一句话 DNA**：用梦境逻辑并置不相关的物体——用精到的真实感画不可能的事
- **视觉语言**：明度对比偏写实但气氛诡异 / 色彩写实描绘"伪真实"空间 / 笔触分两派：精到写实（达利）或自动主义（米罗）/ 构图梦幻空间、比例错乱、并置无关物
- **代表画家**：达利（幻觉的写实）、马格利特（哲学的图像谜题）、米罗（自动主义的儿童符号）、恩斯特（拓印法 frottage 的发明者）、德尔沃（月光下的骷髅街）
- **适合表达**：潜意识、梦境、欲望、荒诞、心理谜题、童年的视觉化
- **可借鉴点**：马格利特"语义错位"——把一个寻常物放在不属于它的语境（如棺材里放苹果、戴帽子的青苹果脸），用最写实的手法画最不可能的并置；图像即思想

### 维也纳分离派（Vienna Secession）
- **年代/地区**：1897—1905，维也纳
- **一句话 DNA**："给每个时代它自己的艺术"——装饰即崇高，金、心理与欲望
- **视觉语言**：明度中调、金色发光 / 色彩金黑、深红、心理冷色 / 笔触平整装饰 / 构图平面图案化、几何与有机形交融
- **代表画家**：克里姆特（金饰象征的极致）、席勒（扭曲人体的先驱）、科柯施卡（心理肖像的重笔触）
- **适合表达**：欲望、心理紧张、装饰的崇高、女性、情色、生死交织
- **可借鉴点**：席勒"扭曲的人体线描"——用扭曲的线条画瘦削身体，关节强调、手指伸张、眼神直戳；适合画心理紧张、不完美的当代肖像

### 至上主义 / 抽象艺术（Suprematism / Abstract Art）
- **年代/地区**：1910s—1920s，俄国为主
- **一句话 DNA**：纯粹几何形与色彩的关系就是全部内容——艺术不再需要"画什么"
- **视觉语言**：明度对比清晰 / 色彩单色或几个原色 / 笔触消失、平整 / 构图几何形漂浮在白底
- **代表画家**：马列维奇（黑方块、白底红方块）、康定斯基（最早的纯抽象，理论家）、埃尔·利西茨基（Proun 系列）
- **适合表达**：纯粹形式、形而上的零度、精神的几何化、"无对象"的冥想
- **可借鉴点**：马列维奇"白底上的几何漂浮"——在白底画一两个简单色块，关系即主题；适合探索"最少的形、最少的色"如何撑起一张画

### 风格派（De Stijl）
- **年代/地区**：1917—1931，荷兰
- **一句话 DNA**：把绘画降到水平/垂直线 + 三原色 + 黑白灰——视觉的乌托邦语法
- **视觉语言**：明度黑白灰 / 色彩红黄蓝三原色 / 笔触平整 / 构图正交网格、色块分布
- **代表画家**：蒙德里安（最严格也最有名）、范杜斯堡（引入对角线的叛逆者）、里特维尔德（设计为主）
- **适合表达**：秩序、乌托邦、纯粹关系、设计性、理性之美
- **可借鉴点**：蒙德里安"网格的呼吸"——直线不是死板的分割，而是色块之间"关系"的张力；适合探索"设计的画面感""几何与比例"

### 四、战后与当代

### 抽象表现主义（Abstract Expressionism）
- **年代/地区**：1940s—1950s，美国纽约
- **一句话 DNA**：把整张画布当作一场身体行动的痕迹——画是艺术家"在场"的证据
- **视觉语言**：分两路——行动画派（波洛克滴洒）/ 色域（罗斯科，见下条）/ 明度对比强 / 色彩能量化、纯颜料直接使用 / 笔触即身体动作的痕迹 / 构图"满版"无焦点（all-over）
- **代表画家**：波洛克（滴洒迷宫）、德·库宁（《女人》系列的暴力笔触）、罗斯科（色场冥想，见下条）、弗朗茨·克兰（黑白巨幅书法）、阿道夫·戈特利布（象形图像）
- **适合表达**：潜意识涌动、能量、自我、宏大情绪、身体的作画痕迹
- **可借鉴点**：波洛克"all-over"——让整张画均匀覆盖、没有视觉中心，让画面变成一片"力的场"；处理"无叙事的纯能量"时的范本

### 色域绘画（Color Field Painting）
- **年代/地区**：1950s—1960s，美国
- **一句话 DNA**：大色块直接作用于观者的情绪——色彩即内容
- **视觉语言**：明度平均、整体一片 / 色彩大面积薄层渗染、低对比 / 笔触消失、染进画布 / 构图色块边缘软边、整体无焦点
- **代表画家**：罗斯科（漂浮色块的冥想）、巴内特·纽曼（"拉链"的崇高）、克利福德·史蒂尔（火焰色域）、海伦·弗兰肯瑟勒（染画法）
- **适合表达**：崇高、冥想、悲伤、神圣、纯粹情绪、纪念性
- **可借鉴点**：罗斯科"色块漂浮"——把色块边缘画成软边虚化的"云"，让色块像悬浮在画布上而不是贴在画布上；当代抽象与情绪表达的核心技法

### 极简主义（Minimalism）
- **年代/地区**：1960s 起，美国
- **一句话 DNA**：把画删到一个几何形、一种色、一种关系——意思越少越有力
- **视觉语言**：明度极度控制 / 色彩极少、单色或几个等值色块 / 笔触消失、工业感 / 构图对称、重复、均等单元
- **代表画家**：弗兰克·斯特拉（"你看到什么就是什么"）、艾尔斯沃斯·凯利（纯色形的硬边）、阿德·莱因哈特（黑色绘画）、阿格尼丝·马丁（极淡网格冥想，跨色域）
- **适合表达**：克制、纯净、冷静、形而上的空、对噪点的反抗
- **可借鉴点**：阿格尼丝·马丁"几乎不可见的网格"——用极淡的铅笔线手绘网格在浅色背景上，做成既严格又温柔的冥想感；适合探索"轻""几乎无"的画面

### 波普艺术（Pop Art）
- **年代/地区**：1950s—1960s，英美
- **一句话 DNA**：把广告、漫画、消费品搬上画布——大众图像就是新历史画
- **视觉语言**：明度高调、平面 / 色彩印刷感的纯色、亮色 / 笔触消失、丝网印刷平涂 / 构图裁切、放大、并置
- **代表画家**：沃霍尔（重复印刷的偶像）、利希滕斯坦（漫画放大成绘画语法）、理查德·汉密尔顿（波普宣言）、罗森奎斯特（广告牌的并置）、大卫·霍克尼（跨过波普的英国画坛大师）
- **适合表达**：消费文化、偶像、媒体、平庸日常的"神话化"、流行
- **可借鉴点**：沃霍尔"重复即意义"——把同一图像印多次，重复本身就变成对偶像/商品的祭礼；处理"图像过载""偶像化"主题

### 光效艺术（Op Art）
- **年代/地区**：1960s，跨国
- **一句话 DNA**：用精确的几何图案在眼里制造振动、运动与幻觉
- **视觉语言**：明度极端黑白对比 / 色彩黑白或补色高对比 / 笔触消失 / 构图几何精密重复
- **代表画家**：布里吉特·赖利（振动条纹大师）、维克多·瓦萨雷里（几何棋盘）
- **适合表达**：视觉本身的能量、运动、感知的边界、纯粹的光学
- **可借鉴点**：赖利"补色振动"——把高对比补色并置成图案，眼睛会自动产生振动错觉；处理"感知""错觉""视觉暴力"主题

### 照相写实主义（Photorealism）
- **年代/地区**：1960s—1970s，美国
- **一句话 DNA**：画得比照片还像照片——但选的视角是相机独有
- **视觉语言**：明度全阶忠实 / 色彩忠实于相机偏色 / 笔触消失、喷枪为主 / 构图反常视角（反光、玻璃、强透视）
- **代表画家**：查克·克洛斯（巨型人脸的马赛克写实）、理查德·埃斯蒂斯（玻璃反光的街景）、奥黛丽·弗拉克、拉尔夫·戈因斯（美式餐厅与车）
- **适合表达**：现代视觉经验本身、玻璃、霓虹、消费景观的冷感、相机的"看"
- **可借鉴点**：埃斯蒂斯"反光即构图"——让玻璃、水洼、车窗的反光成为画面的真正主角；当代都市题材里"画反光"几乎是必修课

### 新表现主义（Neo-Expressionism）
- **年代/地区**：1970s 末—1980s，跨国（德、意、美为主）
- **一句话 DNA**：带着历史伤疤回到具象——粗砺笔触 + 神话/历史/媒体图像的混合
- **视觉语言**：明度对比强 / 色彩刺眼、不调和 / 笔触厚重野蛮 / 构图平面化、人物符号化、图像拼贴
- **代表画家**：安塞尔姆·基弗（历史废墟的史诗）、乔治·巴塞利兹（倒置的人物）、朱利安·施纳贝尔（盘子肌理的粗砺）、大卫·萨利（图像并置）、A.R. 彭克（原始符号）
- **适合表达**：历史创伤、神话、文化记忆、个人神话、媒体的图像过载
- **可借鉴点**：基弗"材料的物质性"——直接用铅、灰烬、稻草、干裂颜料、烧灼痕迹堆出画面；适合处理历史/创伤/重题材，让材料本身成为内容

### 当代具象（Contemporary Figurative）
- **年代/地区**：1980s 至今，跨国
- **一句话 DNA**：把人体重新当主题——但带着所有现代主义的伤、媒体的看、性别的疑
- **视觉语言**：明度多变 / 色彩肉色调系（含绿紫蓝灰）/ 笔触可见、肉感、有时粗 / 构图裁切、特写、不寻常视角
- **代表画家**：卢西安·弗洛伊德（厚涂肉感的肖像极致）、爱丽丝·尼尔（心理肖像）、珍妮·萨维尔（巨幅肉体的张力）、玛琳·杜马斯（水彩般的悲悯肖像）、埃里克·费舍尔（中产阶级的疏离）、刘小东（中国当代具象）
- **适合表达**：身体、心理、亲密关系、身份、当代人的肉身存在、疾病、衰老
- **可借鉴点**：卢西安·弗洛伊德"肉的笔触"——用短促的方向性笔触一笔一笔堆出肉体，颜色里掺绿紫蓝灰；肖像"高级感"和"肉感"兼得的当代配方

### 涂鸦 / 街头艺术（Graffiti / Street Art）
- **年代/地区**：1970s 起，美国发源，全球
- **一句话 DNA**：从地铁车厢到画廊——亚文化的字体、图像与公共性进入艺术
- **视觉语言**：明度高对比 / 色彩饱和原色与喷漆荧光色 / 笔触喷漆、马克笔、模板 / 构图抢占视觉、重复签名、拼贴
- **代表画家**：让-米歇尔·巴斯奎特（neo-expression 与涂鸦的交叉）、基斯·哈林（图标化的人形）、Banksy（模板政治讽刺）、OSGEMEOS（巴西双胞胎）
- **适合表达**：亚文化、政治讽刺、街头能量、反体制、原生性、城市噪点
- **可借鉴点**：巴斯奎特"涂鸦语法"——把文字、解剖图、划掉的词、原始符号并置；适合处理"原生性""反学院""身份"主题

## 第二部分：东方脉络

### 中国水墨写意（Chinese Ink Wash / Xieyi）
- **年代/地区**：宋元以后成熟，中国
- **一句话 DNA**：以笔墨的浓淡干湿与留白传递物象之神，形在似与不似之间
- **视觉语言**：明度即墨色（焦、浓、重、淡、清五色）/ 色彩淡彩为辅 / 笔触即书法用笔（中锋、侧锋、逆锋、飞白）/ 构图留白、虚实相生、卷轴分段
- **代表画家**：梁楷（泼墨减笔的开创者）、徐渭（大写意花鸟的狂）、八大山人（极简的孤傲）、石涛（"一画"理论家）、齐白石（工写兼能的现代大师）、傅抱石（近代山水皴法革新）
- **适合表达**：意境、文人气质、孤清、野逸、物的精神、东方哲思
- **可借鉴点**：八大山人"极简的视觉语法"——一张白纸上一只鸟一条鱼，留白即是水是天；当代极简的本土源头，"少即是多"的东方版

### 工笔重彩（Gongbi / Meticulous Heavy Color）
- **年代/地区**：唐宋以来，中国
- **一句话 DNA**：精微的线描轮廓 + 矿物色的层层晕染，追求"工"到极致
- **视觉语言**：明度均匀细腻 / 色彩矿物纯色（石青、石绿、朱砂、蛤粉）/ 笔触线描匀细、平涂三矾九染 / 构图精谨、装饰性强
- **代表画家**：周昉（簪花仕女）、张萱（捣练图）、顾闳中（韩熙载夜宴图）、宋徽宗（瑞鹤图）、何家英（当代工笔人物）
- **适合表达**：精致日常、宫廷审美、女性、装饰性、细节沉醉、博物式观看
- **可借鉴点**：宋徽宗"物候的精微"——画一只鸟一枝花都用最克制最精准的线，把"自然史"画成"对象学"；适合"细节控""博物学"题材

### 日本浮世绘（Ukiyo-e）
- **年代/地区**：17—19 世纪，日本江户
- **一句话 DNA**："浮世"= 当下正在过的世界；大众消费的木版画——歌舞伎、艺伎、相扑、风景
- **视觉语言**：明度平面 / 色彩纯色平涂、黑轮廓（菱纹、靛蓝、茜红）/ 笔触线条精炼（无影）/ 构图大胆裁切、俯瞰、超透视
- **代表画家**：葛饰北斋（《神奈川冲浪里》）、歌川广重（东海道五十三次的风雨）、喜多川歌麿（美人大头）、东洲斋写乐（歌舞伎役者大首绘）
- **适合表达**：市井、时尚、风景的瞬间、戏剧性表情、当下感、流行
- **可借鉴点**：广重"风雨即构图"——用斜线大雨/大雪切构图，物在自然力中被压低变形；天气从来是构图元素而非背景

### 日本画（Nihonga）
- **年代/地区**：明治以来，日本
- **一句话 DNA**：在西方油画冲击下重新定义"日本画"——岩彩矿物颜料 + 绢本 + 日本母题
- **视觉语言**：明度中调 / 色彩岩彩的颗粒感、矿物发色 / 笔触细腻不露痕 / 构图装饰平面、传统母题（樱花、富士、美人、四季）
- **代表画家**：横山大观（"朦胧体"的发明）、菱田春草、速水御舟、东山魁夷（青色风景冥想）、平山郁夫（丝路）
- **适合表达**：东方冥想、自然、传统母题的当代化、安静
- **可借鉴点**：东山魁夷"青色调子的冥想风景"——把风景降到极少的色阶、用岩彩颗粒感产生安静的发光感；适合当代"东方感""冥想感"题材

### 当代东方水墨（Contemporary Eastern Ink）
- **年代/地区**：1980s 至今，中/日/韩/台
- **一句话 DNA**：用笔墨语言回应当代经验——既是水墨也是观念
- **视觉语言**：明度多变、有抽象感 / 色彩或墨或岩彩或综合材料 / 笔触变形、解构、再发明 / 构图或留白或满版或装置
- **代表画家**：徐冰（《天书》的文字水墨）、谷文达（伪汉字）、刘国松（"摈中锋"的革命）、刘丹（微观山水）、李华生（线网格冥想）
- **适合表达**：传统与当代的张力、文化身份、东方哲学的当代化、水墨的边界
- **可借鉴点**：刘国松"摈中锋笔法"——用拓印、揉纸、撕揭、纸筋代替毛笔，把"笔墨中心"打破；探索"非笔的水墨""材料的可能"

### 藏传唐卡（Tibetan Thangka）
- **年代/地区**：11 世纪至今，藏区及喜马拉雅文化圈
- **一句话 DNA**：可移动的修行工具——精确的几何度量经 + 矿物色 + 严整图像学
- **视觉语言**：明度均匀高调 / 色彩矿物五色（红蓝绿白黄）+ 大量金 / 笔触极细、平涂 / 构图中央主尊 + 对称眷属 + 山水背光
- **代表画家**：传统匿名（修行者），近代如安多强巴（融入写实）
- **适合表达**：修行、神圣、冥想对象、图像学的严整、信仰系统
- **可借鉴点**：度量经的几何严格——所有比例都按经文规定，神圣感来自比例本身的纪律；处理"秩序""崇高"时，几何纪律比自由更有力

## 第三部分：其他传统

### 拜占庭圣像画（Byzantine Icon）
- **年代/地区**：6—15 世纪，拜占庭及东正教世界
- **一句话 DNA**：金色平面里的灵性身体——不是写实，是窗户背后的"真理"
- **视觉语言**：明度平均、金光覆盖 / 色彩蛋彩的矿物色、金箔为底 / 笔触平涂、反相高光（提亮而非加阴影塑造）/ 构图正面、对称、平面、无空间纵深
- **代表画家**：安德烈·鲁布廖夫（俄罗斯圣像巅峰，三位一体）、曼努埃尔·潘塞林诺斯、Theophanes the Greek
- **适合表达**：灵性、神圣、永恒、超越时间的人物、冥想对象
- **可借鉴点**：金色平面背景——把空间背景换成纯金或纯色平面，人物立刻获得超越时间的神圣感；适合"灵性""纪念性"肖像

### 波斯细密画（Persian Miniature）
- **年代/地区**：13—17 世纪，波斯
- **一句话 DNA**：史诗、爱情与王室的微观叙事——平面几何色块的精微宇宙
- **视觉语言**：明度均匀高调 / 色彩矿物纯色（青金、朱砂、孔雀绿、金）平涂 / 笔触极细、不塑造体积 / 构图俯视全景、不分前后景层叠、多时空并置
- **代表画家**：卡马尔·丁·毕扎德（开创大师）、Sultan Mohammad、Reza Abbasi
- **适合表达**：叙事、爱情诗、宫廷、神话、文学场景
- **可借鉴点**：俯视平面层叠构图——拒绝透视，把不同时空的事件并置在同一画面；叙事密度极高的另一条路径，适合"长卷式"叙事

### 莫卧儿细密画（Mughal Miniature）
- **年代/地区**：16—18 世纪，印度莫卧儿宫廷
- **一句话 DNA**：波斯细密画 + 印度本土色彩 + 西方写实主义的三重融合
- **视觉语言**：明度均匀 / 色彩矿物色更饱和、暖调（朱砂、靛蓝、金）/ 笔触极细但带体积感与明暗 / 构图俯视全景 + 焦点人物居中
- **代表画家**：Basawan（引入西法明暗）、Abu'l-Hasan、Govardhan、Mansur（动物与植物博物画）
- **适合表达**：宫廷叙事、自然史（动植物）、文化交流、华丽日常
- **可借鉴点**：Mansur 式"博物画法"——把动物当肖像画，姿态严谨、毛发羽毛极致精微；适合当代博物学、自然题材的精微路线

### 拉美壁画运动（Mexican Muralism）
- **年代/地区**：1920s—1950s，墨西哥
- **一句话 DNA**：革命后用公共壁画讲述人民历史——艺术是政治教育
- **视觉语言**：明度对比强 / 色彩土红、靛蓝、赭黄、墨黑——印第安传统调色板 / 笔触粗粝有力 / 构图史诗群像、金字塔式层叠
- **代表画家**：迭戈·里维拉（叙事史诗）、大卫·西凯罗斯（实验材料与动势）、何塞·克莱门特·奥罗兹科（批判的悲剧）、弗里达·卡罗（同代精神但小尺幅）
- **适合表达**：阶级、革命、人民、历史史诗、公共性、纪念碑
- **可借鉴点**：里维拉"叙事群像的层叠"——一张画里塞进劳动、革命、殖民、神话多层叙事；适合大尺幅、长卷、墙绘、需要"宏大叙事"的项目

## 附录：如何选派别（决策提示）

当画者提出主题/情绪时，可以按几个轴快速定位：

### 1. 按情绪温度
- 冷/克制 → 极简、新古典、色域、八大自然
- 暖/激情 → 浪漫、表现、野兽、新表现
- 暗黑/焦虑 → 表现、象征、蒙克派、基弗
- 亮/欢愉 → 印象、野兽、洛可可、纳比、波普

### 2. 按对象
- 人物肖像 → 文艺复兴、巴洛克、维也纳分离派、当代具象
- 人体 → 文艺复兴、新古典、当代具象（弗洛伊德、萨维尔）
- 风景 → 哈德逊河派、印象派、弗里德里希式浪漫、东山魁夷
- 静物 → 荷兰小画派（巴洛克）、夏尔丹、莫兰迪式灰调
- 室内 → 维米尔、纳比（博纳尔/维亚尔）、霍普式几何切光

### 3. 按媒介/风格
- 写实 → 文艺复兴、巴洛克、新古典、现实主义、照相写实
- 写意笔触 → 水墨写意、梵高、表现主义、新表现
- 抽象 → 抽表、色域、极简、至上主义、风格派
- 装饰平面 → 纳比、浮世绘、克里姆特、工笔、日本画
- 观念并置 → 超现实、波普、新表现、街头

### 4. 按画幅野心
- 小品私密 → 维米尔、纳比、莫兰迪、浮世绘
- 史诗大尺幅 → 哈德逊河派、巴洛克天顶、壁画运动、基弗、色域

### 5. 按时间紧张度
- 静止冥想 → 色域、八大自然、极简、弗里德里希
- 瞬间定格 → 印象派、维米尔、照相写实
- 运动/时间 → 未来主义、巴拉、德·库宁
- 永恒/无时间 → 拜占庭圣像、文艺复兴、唐卡

---

> 给陪练 agent 的最后一句：选派别不是选标签，是选**工作方法**和**视觉机制**——"借"的是某个具体技法（晕涂、补色并置、all-over、装饰溶解、风雨切构图），而不是"整体风格模仿"。把流派当成可拆解的工具箱，每次只偷一两个机制进当下的画里。

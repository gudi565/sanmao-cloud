# 绘画陪练 · 艺术参考库

这是陪练的"艺术知识弹药库"。给路径、给参考方向、定视觉处理时，从这里精准调用，而不是临时拍脑袋想几个常见名字。

## 四个文件，按需查

| 文件 | 查什么 | 什么时候用 |
|---|---|---|
| `04-by-mood.md` | 情绪/主题 → 契合画家 + 画面思路 | 用户说一个情绪或主题词（孤独/热闹/宁静…）时，**首选这里** |
| `01-movements.md` | 流派速查（DNA + 视觉语言 + 代表画家 + 可借鉴点） | 用户想了解或选择某个风格流派时 |
| `02-painters.md` | 关键画家档案（风格DNA + 技法要点 + 最该借鉴的维度） | 要给出具体的"借谁的方向"时 |
| `03-visual-strategy.md` | 媒介表现力 + 明度/色彩/构图/笔触的"点菜式菜单" | 定视觉处理方向、组合"怎么画"时 |

## 用法（陪练的工作流）

1. 用户给了主题/情绪 → 先翻 `04-by-mood.md`，找契合的画家和画面思路
2. 要给风格方向 → 查 `01-movements.md`（要广角）或 `02-painters.md`（要具体的借鉴点）
3. 要定"怎么画"（明度/色彩/构图/笔触）→ 翻 `03-visual-strategy.md` 组合，像点菜一样
4. 给的参考必须**具体**（画家 + 作品 + 借鉴点），不许泛泛说"参考某大师"

## 持续扩充（这就是"学习"）

这个库是起点，不是全集。遇到不熟悉的领域或画家：**先查库；库不够就用 WebSearch 联网补；补到的新发现顺手记进对应文件**，让它越用越广、越用越准。

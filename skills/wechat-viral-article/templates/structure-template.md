# 凤头·猪肚·豹尾 结构模板 + 情绪曲线

## 一、三段式骨架

```
┌─────────────────────────────────────┐
│ 凤头(开头 10-15%)                    │
│ 3 句话内抓住读者                      │
│ 3 种开篇法任选其一 ↓                  │
├─────────────────────────────────────┤
│ 猪肚(主体 70%)                        │
│ 3-5 个小标题推进                       │
│ 每段:观点 + 案例/故事/数据 + 钩子      │
├─────────────────────────────────────┤
│ 豹尾(结尾 15%)                        │
│ 升华 + 金句 + CTA                     │
│ 留余味,不总结                         │
└─────────────────────────────────────┘
```

## 二、3 种开头法(凤头)

### 1. 故事切入
用一个具体人物/场景开头,制造代入感。
> "上周三晚上 11 点,朋友小林发来消息:我又想辞职了。这已经是她今年第 4 次说这句话。"

> **防编造提醒**:故事开头的人物 + 具体数字(次数/金额/年限)若为虚构,按 SKILL.md 数据真实性硬红线处理——正文只写无数字的现象叙述,具体数字进【发布前待填/待核】区标 `[示例数据]`,不得白描成真人真事。

### 2. 反常数据
抛出一个违反直觉的数据/事实,制造认知冲突。
> "中国有 2 亿人在灵活就业,但其中超过 60% 的人,收入还不如上班时。"

> **防编造提醒**:反常数据必须是真实可查的(用 WebSearch 核实来源);编造的"反常数据"只能进【发布前待填/待核】区,不得直接进正文。

### 3. 犀利提问
直接抛出戳心的问题,让读者对号入座。
> "你有没有发现,越努力的人,好像越焦虑?"

**开头禁忌**:大段背景介绍、名人名言开场、定义解释(论文腔)。

## 三、主体(猪肚)小标题模板

每个小标题要能**独立成立**,扫一眼小标题就读懂全文逻辑。

| 段式 | 模板 | 适合 |
|------|------|------|
| 递进式 | 不是 A,而是 B / 表面是 A,背后是 B | 观点文 |
| 阶梯式 | 第一层…第二层…第三层… | 方法论 |
| 对比式 | A 这样,B 那样 | 盘点对比 |
| 故事式 | 人物 A 的三个选择 | 人物稿 |

**每段结构**:小标题 → 核心观点(1-2 句)→ 案例/故事/数据支撑 → 段末钩子(牵引下一段)。

## 四、结尾(豹尾)模板

- **升华式**:把具体话题拔高到普遍意义。
- **金句收尾**:用一句金句定格全文情绪。
- **行动号召**:自然过渡到 CTA(关注/社群/课程)。

**结尾禁忌**:总结全文(读者已经看过了)、强行升华到"国家民族"(假大空)。

## 五、情绪曲线(完读率命脉)

```
情绪
 高 │                ╭──╮        ╭───(升华)
    │               ╱    ╲      ╱
    │      ╭──╮   ╱      ╰─╮╭─╱
    │     ╱    ╲ ╱         ╳
 低 │╭───╯      ╲         ╱
    ╰┷┷┷┷┷┷┷┷┷┷┷┷┷┷┷┷┷┷┷┷┷┷→ 段落
     开头  认同  惊讶  共鸣  信任  高潮转折  结尾
```

> 纯文字版(防手机/非等宽字体错位):**波峰**→开头(好奇/痛点)、惊讶(反常识小高峰)、共鸣(戳心)、高潮转折(全文最震撼)、升华;**波谷**→认同、信任(叙事铺陈段)。全文至少 2 个波峰,平铺必死。

**关键节点**:
1. 开头:好奇/痛点抓人(高起点)。
2. 认同:让读者点头"对对对"。
3. 惊讶:抛出反常识信息,情绪小高峰。
4. 共鸣:戳到情绪深处。
5. 信任:用数据/案例建立权威。
6. 高潮转折:全文最震撼的点。
7. 结尾:升华留余味。

**铁律**:每段结尾必须留钩子(悬念/问题/未解之谜),牵引读者往下滚。平铺直叙的长文必死。

## 六、使用流程

1. 先定开头法(3 选 1)。
2. 列主体 3-5 个小标题(每个写出一句话核心观点)。
3. 定结尾升华点 + CTA 类型。
4. 为每段标注情绪点,检查曲线是否有起伏(不少于 2 个波峰)。
5. 检查每段是否有钩子牵引下一段。
6. **字数预算兜底(防写完才发现字数不够)**:按 SKILL.md Step 4 的块预算表,把目标字数拆到"开头 / 每个主体段 / 结尾",写在大纲上(如"段一 350 字")。**段数定上限:3 段主体只够撑 ~1500-2200 字;目标 ≥ 2500 字时主体必须 4-5 段**——否则每段要写到 500+ 字,违背短段排版规范,实际执行几乎必然字数短缺(动态实测的 1462 字事故即由此发生:4 段每段只写了 ~200 字)。

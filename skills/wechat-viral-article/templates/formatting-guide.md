# 公众号移动端排版规范 + 引流话术模板

## 一、移动端排版规范

公众号在手机上阅读,屏幕小、注意力短。深度阅读 ≠ 大段文字。

### 段落规范

| 项目 | 规范 | 说明 |
|------|------|------|
| 段落长度 | 60-100 字/段(手机 3-5 行) | 超长必拆,不要心疼 |
| 段落间距 | 段间空一行 | 视觉留白 |
| 小标题 | 独占一行 + 加粗 | 扫读时能抓住结构 |
| 行间距 | 默认或 1.5 | 公众号后台设置 |

### 加粗策略

- 全文加粗 **3-5 处**,标关键句 / 金句。
- 加粗多了 = 没加粗,要克制。
- 不要整段加粗(等于重点失效)。

### 配图节点

- 长文每 **600-800 字** 一个配图位。
- 在正文中标注:`[配图建议:一张关于 XX 的图,风格 XX]`。
- 配图风格保持一致(实拍/插画/极简,读 `_config.json` 的 `image_style`)。
- 只给文字建议,不假装能生成图片,提醒用户用正版图库。

### 小标题层级

```
## 一级小标题(主体段落,加粗独占一行)

正文正文正文...

### 二级小标题(段落内分点,可选)
```

公众号最多用到二级,层级太深会让手机端排版混乱。

### 信息流摘要(标题下展示行)

公众号信息流展示时,标题下方还有一行摘要(用户可手动设置,否则抓取正文首句)。这行直接影响点击,不可忽视。

- **长度**:1-2 句,15-40 字。
- **与标题关系**:呼应但不重复标题,不剧透核心结论,制造"点击—阅读"的二次悬念。
- **示例**:
  - 标题《月薪两万,存款为零:这届年轻人的钱都去哪了》
  - 摘要:不是不赚钱,是花钱的地方你根本想不到——我把账单一笔笔拆开了。
- **避坑**:不要直接复制正文首句(常平淡无钩子);不要剧透结论("所以原因是 X"——读者就不用点开了)。

## 二、封面图设计(信息流点击的另一生死线)

信息流推荐机制下,封面图与标题共同决定点击率,很多账号封面图的作用甚至大于标题。**标题 + 封面 + 摘要** 是信息流里的"点击三件套",缺一不可。

### 封面图三要素

| 要素 | 说明 | 自检 |
|------|------|------|
| 主体 | 一眼能看出"这篇讲什么"的视觉焦点 | 缩到手机缩略图大小仍能辨认主体 |
| 情绪 | 封面传递的情绪要与标题/正文一致 | 痛点文用压抑色调,干货文用明亮对比 |
| 留白 | 不要塞满,留呼吸感,给文字留位置 | 主体占画面 40-60%,四周留白 |

### 文字封面 vs 图片封面

| 类型 | 适用 | 做法 |
|------|------|------|
| 文字封面(纯文字 / 大字报) | 观点文、争议文、强金句文 | 大字 + 高对比色(白底黑字 / 黑底黄字),字数 ≤ 12 字,字体粗重 |
| 图片封面(实拍 / 插画) | 故事文、人物稿、生活类 | 有具体人物/场景,情绪代入强;可叠加一句小字标题呼应 |

**经验**:信息流里文字封面的点击率通常更稳(缩略图也清晰),图片封面情绪更强但风险更高(缩略图看不清就废)。

### 与标题的呼应关系

- **互补**:标题说 A,封面补 B(例:标题《那些深夜崩溃的成年人》+ 封面一个人深夜对窗的背影)。
- **强化**:标题和封面同主题不同表达,放大同一个钩子。
- **避雷**:封面与正文无关(骗点击,伤账号权重)、封面文字与标题完全重复(浪费一个钩子位)。

### 封面图避坑清单

- [ ] 文字过小:缩略图(手机信息流里只有指甲盖大)看不清 = 等于没写字。
- [ ] 主体模糊:远景、多人、杂乱背景 → 手机端看不清主体。
- [ ] 与正文无关:纯为博眼球用美女/惊悚图,点进去文不对题 → 高打开低完读,反伤推荐权重。
- [ ] 文字过多:封面塞超过 15 字 → 信息过载,读者放弃解析。
- [ ] 色彩混乱:超过 3 种主色 → 不高级、不专业。

> 本 skill 只产出封面图**设计方案**(主体/情绪/文字/配色),不生成图片。用户据方案用 Canva / 创客贴 / 公众号后台封面工具制作。

## 三、排版自检清单

- [ ] 所有段落都在 3-5 行内(手机端)?
- [ ] 小标题都加粗且独占一行?
- [ ] 关键句/金句加粗(3-5 处,不滥用)?
- [ ] 配图节点已标注(每 600-800 字一处)?
- [ ] 段落间留白?
- [ ] 全文扫读小标题能读懂逻辑?

## 四、引流话术模板(文末自然过渡)

硬广割裂,自然过渡才不伤完读率。结构:**话题延伸 → 价值承诺 → CTA**。

### 类型 1:引导关注(follow)

**有 `_config.json` 的 `account_name` 时**(直接用真实名字,无需占位):

> 写到这里,其实关于 [相关话题] 还有很多想聊的。
> 如果你也关心 [目标人群痛点],欢迎关注 **{account_name 实际名字}**。
> 后续会继续聊 [下期预告方向],我们下篇见。

**无 `account_name` 时(fallback,正文不出现占位符)**:

> 写到这里,其实关于 [相关话题] 还有很多想聊的。
> 如果你也关心 [目标人群痛点],欢迎关注,别走丢。
> 后续会继续聊 [下期预告方向],我们下篇见。

> **铁律**:`account_name` 缺失时,**不要在正文 CTA 里留 `[账号名]` / `[你的公众号名]` 这种占位符**(用户复制到后台就得手动改,违背"可直接粘贴")。改用上面的 fallback 话术(用"欢迎关注,别走丢"这类不带名字的自然句式),同时在交付顶部【发布前待填/待核】区登记一条:"文末 CTA 未填具体公众号名(配置缺失),如需替换为实际账号名,在 CTA 行补充即可"。

### 类型 2:引流社群(community)

> 这篇文章只能聊到这,但很多具体的问题,其实更适合一起讨论。
> 如果你也在经历 [目标人群处境],想和同频的人交流,
> 欢迎加入我们的 [社群名],后台回复「[关键词]」即可。

### 类型 3:课程/产品(course/product)

> [本篇核心痛点] 说到底,不是一篇文章能解决的。
> 如果你想要更系统的 [解决方案],
> 我们准备了一套 [产品名],帮你 [核心收益]。
> 后台回复「[关键词]」了解详情。

> **类型 2/3 铁律(与类型 1 同,防占位符污染正文、兑现"可直接粘贴")**:`[社群名]` / `[产品名]` / `[关键词]` / `[目标人群处境]` / `[核心收益]` 都是待填项。若 `_config.json` 或用户本轮没给齐真实社群名/产品名/关键词,**不得把这些方括号占位符留在正文 CTA 里**(用户复制到后台又得手动查找替换)。二选一:(a) **改用无占位符的自然句式**——用通用词代替空白占位(如"欢迎加入我们的读者群,后台回复「进群」即可"「进群」是可直发的通用词,不是 `[关键词]` 占位);(b) 正文 CTA 写到"后台回复关键词即可"为止,**具体社群名/产品名/关键词连同 `[待填]` 标一起登记到交付顶部【发布前待填/待核】区**。SKILL.md Step 7 的"正文纯净自检"会扫这一条:正文里出现任何方括号占位符即判为不通过,必须移出。

### 类型 4:无引流(纯内容号)

> 最后想说:
> [一句金句式收尾]。
> 愿你我都能 [美好愿景]。

## 五、引流避坑

- **位置**:必须文末,不要插在正文中间(割裂阅读)。
- **过渡**:用"话题延伸"自然引出,不要硬切"对了,顺便说一句"。
- **合规**:避免"转发抽奖""必看""不转不是中国人"等违规词。
- **外链**:微信限制外部跳转,引流用"后台回复关键词"或"阅读原文",不要直接外链。
- **频率**:不要每篇都强推产品,内容号 3-5 篇内容穿插 1 次引流为宜。

## 六、完整成稿交付格式

最终给用户的成稿,建议按以下结构组织,方便直接复制到公众号后台:

```
【发布前待填/待核】(置顶;集中所有占位符、示例数据、待核实项,每条标 [待填]/[待核];无则写"无")

【标题】(Top 3 推荐,任选)

【摘要】(1-2 句,15-40 字,信息流标题下展示,呼应标题不剧透)

【封面图建议】(主体/情绪/文字方案/配色)

【正文】(纯净可直粘:无占位符、无 [示例数据] 标、无"约 N 字"标注)
(开头:凤头 3 句抓人)

## 小标题 1
正文... [配图建议:...]

## 小标题 2
正文...

...

(结尾:豹尾升华 + 金句 + CTA——CTA 用无占位符话术)

【配图节点清单】
- 位置 1:...
- 位置 2:...

【金句清单】
- 句 1(位于:小标题 X)
- 句 2(位于:段末高潮)
- ...

【排版要点】
- 加粗:X 处
- 配图:X 处
- 引流:类型 + 话术
- 字数:实际 X 字 / 要求 Y 字(口径:正文中文字符数)
```

> **交付铁律**:占位符、`[示例数据]` 标、`(发布前核实)` 标注、"约 N 字"字样,只允许出现在【发布前待填/待核】块和【排版要点】里;【正文】块必须做到复制进公众号后台即可发布、无需任何查找替换。

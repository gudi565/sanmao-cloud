# 公众号爆款长文

> 输入一个主题,产出可直接复制到公众号后台的成稿——不是替你写字,而是把 10w+ 文章背后的爆款骨架装进流程。

## 这是什么

这是一个公众号长文生产 skill,解决的核心问题是:**写长文全凭感觉、每次从空白文档硬憋**。它把"选题—标题—结构—情绪—金句—排版—引流"这套工业化打法固化成 8 步工作流,内置 10w+ 标题 10 公式、凤头猪肚豹尾长文结构、情绪曲线、金句引擎等可复用方法论。最终产出的是可直接粘贴发布的成稿,并附 10 个标题候选、金句清单、排版说明与引流设计。适合 1500-5000 字的中长文场景。

## 30 秒上手

1. **安装**:把整个 `wechat-viral-article/` 文件夹放到 `~/.claude/skills/` 下(用户级),或项目级 `.claude/skills/` 下。
2. **调用**:在 Claude Code 里输入 `/wechat-viral-article <主题>`,可附字数。
3. **拿结果**:按 skill 的 8 步流程走完,得到分六块打包的交付物,复制即用。

调用示例:

```
/wechat-viral-article 敏感肌平价水乳推荐 2500字
/wechat-viral-article 为什么这届年轻人存不下钱
```

## 它能帮你做什么

- **10 个标题做 AB 测试**:套用经典 8 公式 + 2 条 2024-2026 信息流新增结构(钩子前置二次反转、具体场景反直觉结论),标注所用公式,推荐 Top 3。
- **凤头猪肚豹尾结构**:3 种开篇法、3-5 个可独立成立的小标题、升华式结尾,避免开头没抓住、中段没递进、结尾没余味。
- **情绪曲线设计**:为每段标注情绪点,保证起伏而非平铺,提升完读率。
- **金句引擎**:嵌入 3-5 句可独立传播的金句(短句/对仗/反差/洞察四要素),分散在小标题、段末高潮、结尾升华处。
- **移动端排版规范**:短段落、关键句加粗、配图节点标注、留白策略。
- **自然引流设计**:文末话题延伸到关注/社群/课程/产品,提供话术模板,避免硬广割裂感。

## 适合谁

- **公众号作者**:一个人运营,缺结构和选题方法论,每篇都要憋半天。
- **品牌内容 / 新媒体团队**:需要稳定产出有质量底线的深度推文,而不是靠灵感。
- **知识付费 / 自媒体工作室**:需要把引流、人设、合规做成可复制的 SOP。
- **想做个人 IP 的人**:有想法但写不出有传播力的长文,需要一个爆款骨架托底。

## 常见问题

- **要不要联网?** 涉及数据、案例、热点话题时建议联网:skill 已开放 WebSearch 工具权限,用于核实引用数据和事实。纯观点 / 个人经验类长文可不联网。无法核实的数据会明确标注"示例数据,发布前请替换",绝不编造。
- **能不能自定义?** 可以。在 skill 目录下放一个 `_config.json`,可配置公众号名称、人设、目标人群、调性、禁用词、引流类型、默认字数等 9 个字段(详见 SKILL.md 末尾)。不配置则用默认值,开箱即用。
- **支持什么平台 / 语言?** 面向微信公众号中文长文场景。凤头猪肚豹尾、情绪曲线等方法论可迁移到其他中文长文平台(知乎专栏、头条号),但排版规范和引流话术是针对公众号设计的。

## 配置(可选)

无需配置即可使用。若想让人设和引流更贴合你的账号,可在 skill 目录下创建 `_config.json`,关键字段:

| 字段 | 作用 | 默认 |
|------|------|------|
| `persona` | 人设(理性/感性/幽默/专业),影响全文语气 | 中性专业 |
| `target_audience` | 目标人群画像,决定选题角度和痛点切入 | 通用读者 |
| `tone` | 调性(formal/casual/sharp/warm) | formal |
| `cta_type` | 引流类型(follow/community/course/product) | follow |
| `forbidden_words` | 禁用词清单(合规或品牌要求) | 空 |
| `default_word_count` | 默认字数 | 2500 |

完整字段见 `SKILL.md` 的【配置】一节。skill 不会主动创建该文件,需用户自行添加。
